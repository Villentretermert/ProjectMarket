# Web / Android client boundary

The accepted English UX is in [design/prototype](../../design/prototype/README.md).
The Web runtime is implemented here in PM-013–018, using HTML/CSS/JavaScript
and the HTTP contract. PM-005 deliberately does not copy a demo into a product client.
Native Android packaging and the home-screen widget remain PM-019/020; SDK acceptance
and device validation were deferred by the owner. No client build step exists yet.
