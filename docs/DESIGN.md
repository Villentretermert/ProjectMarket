# Дизайн MarkeTOB · PM-003

Интерактивный прототип: `design/prototype/index.html`. Это проверяемый дизайн с синтетическими данными и действиями в памяти браузера. Он не подключён к API, не создаёт аккаунты, заявки или ключи и сбрасывается после перезагрузки. Все экраны на английском. Старый `design/marketob-concept.html` — исторический набросок, не актуальная спецификация.

## Навигация и сценарии

Web: список Channels слева, содержимое справа. До 650 px список и канал показаны последовательно; **All channels** возвращает назад. Основные разделы — Channels, My Space, Studio. Значок пользователя открывает макет локального входа. Google и облачные push отложены по решению владельца.

1. **B2B Alice:** Studio → Create bot → одноразовый placeholder registration credential → Hide → Simulate first bot update → Configure channel → Preview → Publish. Публикация недоступна до первых данных. Public или Selected members; в демонстрации выбран Bob. Реальная регистрация, управление grants и ключами будут реализованы отдельно.
2. **B2C Bob:** Channels → Northstar Shop → Save channel → Send request → Request sent. Кнопка меняется на View request; повторное нажатие открывает существующую заявку. Processing означает обработку; Confirmed — ответ бота, а не оплату. Unknown требует проверки состояния перед повторной отправкой.
3. **My Space:** добавление news/product/chart из разных источников, перестановка и удаление, темы Blue/Ink, Comfort/Compact. Числовой chart переключается между bars/table; текст не превращается в график.
4. **Обмен:** Share layout → MT-DEMO-001 → Preview import → Import as Carol. Копируются только ссылки на блоки и настройки оформления. Private block показывает Access required без данных и времени обновления. Код работает только в текущей демонстрационной сессии; реальный формат определяет PM-004.
5. **Виджет:** Preview states → Widget mockup. Публичный новостной источник показывает заголовки/время; закрытый без доступа — Access required. Это HTML-макет; APK и настоящий виджет не проверены.

## Состояния и компоненты

Preview states переключает Loading, No data, Offline/stale, Refresh error, Access revoked, Source unavailable, Unsupported layout. Offline показывает дату сохранённого обновления и блокирует отправку новой заявки/публикацию. Source unavailable не должно удалять остальные блоки личной страницы. Отзыв прав очищает закрытый контент. Реальные сетевые переходы, очистка кеша и контроль прав — задачи backend/client, не возможности этого прототипа.

Компоненты: ChannelList, ChannelHeader, NewsBlock, ProductBlock, ChartBlock, RequestStatus, BlockEditor, ShareImport, Studio, LocalAccount, NewsWidgetMock, StatusCard. У блока есть источник и время; график имеет текстовое описание и табличное представление. Формы подписаны, статус объявляется через live region, навигация отмечает текущий раздел. Видимый focus и Skip to content доступны с клавиатуры.
