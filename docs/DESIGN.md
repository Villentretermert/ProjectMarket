# Предварительный дизайн MarkeTOB

Это визуальная гипотеза для обсуждения; полноценный UX/prototype — PM-003. Демонстрационные товары, цены, новости и графики не являются живыми данными. Интерфейс на английском, пояснения проекта на русском.

## Навигация

На Web слева список витрин с аватаром, последним обновлением и кратким описанием, справа активный канал. На Android сначала список Channels, затем содержимое выбранного канала. Основные разделы: **Channels**, **My Space**, **Studio**; B2B роль не требует отдельного аккаунта.

Похожесть на Telegram — в плотном списке каналов, понятном переходе назад и знакомой структуре. В содержимом используются news/product/chart blocks, а не бесконечная переписка. У каждой витрины видны источник, статус доступа и свежесть.

```text
MarkeTOB                         Channels  My Space  Studio
┌────────────────────┬──────────────────────────────────┐
│ Saved channels     │ Northstar Shop      ☆ Save      │
│ Northstar Shop     │ Product cards / Availability    │
│ Daily Brief        │ Notebook · €18 · Send request   │
│                    │ Request status: Pending         │
│ My Space           │ Add block to My Space           │
└────────────────────┴──────────────────────────────────┘
```

## Сценарии

**B2B:** Google sign-in → Studio → Connect a bot → одноразовая выдача credential → инструкция интеграции → первые данные → Configure page → Preview → Publish → Copy link. У ключа есть Rotate/Revoke; после выдачи в интерфейсе остаётся prefix, а не полный секрет.

**B2C:** Open link → View channel → Sign in with Google → Save channel → выбрать товар → Send request → Request sent → результат бота. Тексты не обещают покупку или оплату, пока бот только обрабатывает заявку.

**Личная страница:** Add block → выбрать доступный канал/блок → переставить → изменить совместимый вид/оформление → Save → Share layout. Друг открывает код → Preview → Import to My Space. Закрытый источник без права показывает Access required; импорт не даёт права доступа.

**Виджет:** Add MarkeTOB widget → выбрать новостной канал → на домашнем экране появляются заголовки и время обновления → касание открывает новость в приложении. Системная частота обновления отличается от live-режима приложения.

## Обязательные состояния

- Loading, No updates yet, Offline · last updated …, Failed to refresh.
- Access required, Access revoked, Source unavailable, Unsupported layout version.
- Request sent, Processing, Confirmed, Failed, Status unknown — с различением транспортного и бизнес-результата.
- Unavailable item, Changed since you opened it — перед действием по устаревшей карточке.
- Push permission denied — функции приложения остаются доступны.

## Предварительное визуальное направление

Спокойные светлая/тёмная темы, собственный синий акцент, компактная боковая панель, чёткая типографика, карточки с невысокой декоративной нагрузкой. Контент и основной action выше второстепенных настроек. Новости могут быть компактным списком или карточками; graph доступен только для числовой серии. На малом экране нет уменьшенной desktop-страницы: панели перестраиваются.

Проверить в PM-003/013: клавиатуру, подписи полей, читаемость, контраст, touch targets, ширины 320–1440 px и реальный Android. Исходный демонстрационный макет хранится в `design/marketob-concept.html`; он не вызывает API и не отправляет заявки.
