# S05 — Фотографии товаров

8 ноября 2026 · дополнение PM-004/013/016 · [issue #36](https://github.com/Villentretermert/ProjectMarket/issues/36).

## Сценарий и вид

Бот передаёт одно необязательное `image` вместе с товаром. B2C видит миниатюру
в Compact list, крупное изображение с `object-fit: contain` в Card и в каталоге
блоков My Space. Изображение не обрезается. Название, цена, наличие и Request
purchase остаются доступны при отсутствии или ошибке фото. Товар без фото
сохраняет прежний компактный вид; повреждённое фото заменяется Photo unavailable.
Текст `alt` описывает предмет для экранного диктора. Фото не является кнопкой.

Предварительный [макет](PRODUCT_PHOTOS.html) использует условный предмет,
не реальную фотографию. Настоящий Web проверяется отдельно после реализации.

## Контракт и границы пилота

- Инженерный первый формат: статический PNG, 8-bit RGB/RGBA/gray, без interlace,
  палитры, анимации и дополнительных метаданных. JPEG/WebP бот предварительно
  преобразует в PNG своим инструментом. Это ограничение реализации, не ответ владельца.
- `image = {media_type: "image/png", data_base64: "…", alt: "…"}`.
  До 96 KiB PNG, стороны 1–512 px; весь message по-прежнему до 256 KiB.
  Сервер проверяет структуру, CRC, размер распаковки и строки/фильтры.
- Новый Python helper подготавливает допустимый PNG и удаляет необязательные
  chunks с EXIF/текстом/профилями. Ingest принимает уже подготовленный PNG:
  сохранённые байты идентичны сообщению, fingerprint/replay не меняется.
- Это необязательное расширение schema_version 1.0: старые сообщения действительны,
  старый сервер новое поле отклонит. Бот включает фото после обновления сервера.
- Изображение хранится внутри текущего payload/истории по прежним срокам; без
  отдельной БД, миграции, публичного URL и внешнего HTTP-fetch. Layout/share
  содержит только ссылку на источник; приватные байты возвращаются после ACL.
- Web создаёт только `data:image/png;base64,…`; CSP добавляет `data:` только
  в img-src. Script/object/connect ограничения сохраняются. Нельзя передать
  HTTP/file/javascript/SVG URL, и браузер не обращается к сайту поставщика.
- Худший snapshot: до 50 × 128 KiB base64 (~6.25 MiB) плюс прочие поля.
  Это ограниченный пилотный транспорт; большая медиатека требует отдельного
  хранилища/эндпоинта. Полная нагрузочная приёмка остаётся отложенной.

## Проверки и порядок

1. Макет и контракт, затем Python validator/helper и примеры Bot API.
2. Renderer каналов, My Space и каталога; широкий экран и 360 px.
3. Тесты PNG/base64/размеров/метаданных/URL; настоящий ingest, replay,
   изменение/удаление фото, private access/revoke/share и ошибка декодирования.
4. Общая Web-регрессия, CI, журнал/отчёт; локальная установка проверенного образа.

Источники формата: [W3C PNG](https://www.w3.org/TR/png-3/),
[MDN img-src](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/img-src).
