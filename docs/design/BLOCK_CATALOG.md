# S03/S04 · Визуальный каталог блоков My Space

8 ноября 2026. Дополнение к PM-016 в [SR-2026-10-25](../follow-ups/STATUS-2026-10-25.md),
[issue #36](https://github.com/Villentretermert/ProjectMarket/issues/36). Приоритет P1.
Текущий объём: дизайн, Web, проверки и локальная поставка. API и формат layout сохраняются.

## Сценарий

B2B публикует страницу как прежде. B2C добавляет доступный канал в избранное,
выбирает его в My Space и видит карточки опубликованных блоков с настоящими данными:
тип, название, краткий текст; для товара — цена, для графика — миниатюра.
Поиск по названию/тексту и фильтр All types / Products / News / Charts помогают выбрать блок.
Кнопка Add to My Space сохраняет ссылку на источник; покупка из предпросмотра невозможна.
Оформление, перестановка, Undo и Preview сохраняют прежнее поведение.

[Макет](BLOCK_CATALOG.html) помечен PROTOTYPE и использует только demo-данные.
На широком экране карточки стоят в несколько колонок, на 360 px — в одну.
В реальном редакторе каталог находится ниже названия/Theme/Density.

## Доступ и состояния

- Loading: прежние данные источника очищаются сразу при переключении.
- Empty: канал ещё не содержит доступных опубликованных блоков.
- No matches: поиск не дал результатов; Clear filters возвращает все карточки.
- Source unavailable: «This item was removed or you no longer have access.» и Check again.
  Не раскрывать название, цену или причину отказа в праве доступа.
- Сетевая ошибка: текст ошибки и Check again. Повтор заново читает права и данные,
  не создаёт заявку и не сбрасывает собственное оформление страницы.
- Отзыв прав, offline, скрытие вкладки, выход: превью удаляются вместе с остальными
  приватными данными. Поздний ответ прежнего источника не возвращает их на экран.
- Сохранение/конфликт и предел 50 блоков: добавление недоступно с объяснением.

## Последовательность и критерии

1. Показать макет и сохранить объём в issue до реализации.
2. Реализовать каталог поверх существующего авторизованного чтения каналов.
3. Добавить повторную проверку недоступного источника без потери черновика.
4. Проверить настоящим Web/API: фильтры, добавление из двух каналов, Undo,
   клавиатуру, 360 px, отзыв/возврат прав, offline, гонку переключения источника,
   безопасный текст и отсутствие покупки из preview.
5. Сохранить фактические снимки, журнал, результат CI и обновить локальную поставку
   только после проверки резервной копии/восстановления по существующему runbook.
