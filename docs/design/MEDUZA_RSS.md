# S06 — источник Meduza для существующих новостных блоков

9 ноября 2026. Дополнение PM-011/024, [issue #36](https://github.com/Villentretermert/ProjectMarket/issues/36).
Интерфейс news/My Space сохраняется. Макет ниже — синтетический пример, не новость Meduza.

```text
My Space / Public feed
┌───────────────────────────────────────────────────────────┐
│ Демо: новости & события                                    │
│ Source: Meduza · https://meduza.io                          │
│ Published: 2026-11-09T00:30:00+00:00                         │
│ Read the full story: https://example.invalid/news/demo-one │
└───────────────────────────────────────────────────────────┘
```

Пользователь открывает канал или ранее добавленные news-блоки в My Space.
Первые пять записей следуют порядку RSS; заголовки сохраняют язык источника,
служебный интерфейс остаётся английским. Ссылка открывает оригинал публикации.
График отражает известные даты записей текущего окна RSS, а не полную историю новостей.

По ответу S06 «медуза» используется `https://meduza.io/rss/all`.
Выбор русской редакции — явно обозначенное рабочее допущение, не отдельный
ответ владельца. `https://meduza.io/rss/en/all` можно задать через `MARKETOB_RSS_URL`.
Старая конфигурация BBC продолжает правильно указывать BBC; неизвестные URL
не получают марку Meduza автоматически.

Бот получает RSS без ключа MarkeTOB, нормализует title/date/link и отправляет
через общий шлюз. `news_1`–`news_5` и `feed_activity`, права и сохранённый layout
не меняются. Полные статьи, description/content:encoded и enclosure не копируются.
Размер XML ограничен 1 MiB, обработка — 100 записей; DTD/entities/redirect запрещены.
Невалидные или отсутствующие даты не подменяются текущим временем.

Повторный одинаковый ответ не создаёт новых ревизий. При сбое источника остаются
прежние данные; процесс повторяет запрос через 300 секунд, поэтому это не гарантия
свежести новостей каждую секунду. Live доставляет уже принятые обновления открытым
клиентам. Настоящий RSS нужен только боту; CI использует синтетический XML.

Приёмка: обе редакции RSS доступны; атрибуция/UTC/безопасный текст проверены;
смена источника сохраняет пять slots; replay/restart и отказ сохраняют данные;
рабочий локальный канал читается существующим аккаунтом/My Space. Обновлять
журнал и ключи бота с удалением файлов для смены источника не требуется.
