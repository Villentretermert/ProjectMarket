# PM-023 · Data & privacy (прототип)

24 октября 2026. [Визуальный макет](PM-023-privacy-prototype.svg).
Это проект сценария, не снимок работающей реализации.

Из верхней панели пользователь открывает Data & privacy. Первая карточка
скачивает JSON с личными данными; конкретный состав уточняется отдельным вопросом.
Вторая показывает последствия удаления и требует текущий пароль. До отправки
необратимой команды показывается отдельное подтверждение с числом затронутых
страниц/workspace и незавершённых заявок. Политика workspace уточняется у владельца.

Повторная отправка заявки на товар при удалении не создаётся. Уже переданные
внешнему боту данные, скачанные пользователями файлы и резервные копии оператора
нельзя обещать удалить через Web. Эти границы должны быть видны до подтверждения.
После успешного удаления очищаются состояние клиента и сессия, открывается вход.

На узком экране карточки идут одной колонкой, кнопки и поля сохраняют подписи.
Используются существующие стили, навигация и плотность MarkeTOB (ответ G01).
Фактический результат и отличия добавляются после реализации и проверки.

Результат текущей независимой работы: новый экран ещё не реализован, политика
уточняется. В существующем Web исправлено закрытие подтверждения покупки при
отзыве источника; [фактический снимок и 48 проверок](../task-results/PM-023.md)
сохранены отдельно от прототипа.
