# PM-018 · L1, 23 октября 2026

**SLO-LIVE выполнен на локальном L1:** 1 500 принятых сообщений и1 500 отрисованных
версий, без пропусков и HTTP/page ошибок. Это проверка 10 ботов и10 клиентов;
100 ботов/100 клиентов/L2/burst пока не проверены и остаются PM-022.

План900s, последняя отправка через899.639s, затем10s на завершение отрисовки.
100 msg/min; четыре news, четыре product и два chart источника; payload3625–13764
байт (news/product <4KiB, chart <32KiB). Один из десяти клиентов создаёт заявку
раз в минуту; независимый bot HTTP GET/ACK/result подтверждает тестовый результат.
Оплаты нет. Реальное приложение работает в десяти видимых headless Edge contexts.

Приём засчитывается только после HTTP200 с durable receipt. Наблюдатель DOM
сверяет одновременно revision и ожидаемый синтетический title после animation
frame, поэтому запрос snapshot сам по себе не считается показом. Это измерение
браузерной отрисовки, не физического экрана монитора. HTTP read/ingest включают
накладные расходы сети и не выдаются за отдельную метрику времени SQL/handler.

В БД1510 receipt (10 начальных +1500 измеряемых),1560 outbox entries; размер
таблиц/индексов временной схемы5 668 864 bytes. После проверки удалена только
созданная тестовая схема. Долговечность при физических сбоях диска этим тестом
не измеряется; restore резервной копии — PM-021.
