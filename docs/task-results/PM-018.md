# PM-018 · Foreground updates

Реализация проходит окончательную проверку. Задача пока не принята.

Polling2s, session cursor10min, bootstrap-before-snapshot, bounded replay/resync,
preferences и generic toasts, текущие права на каждом poll. Migration010,
updates.py и live.js связывают durable outbox с открытым Web. Индивидуальные
статусы читаются GET, новая покупка от обновления не создаётся.

Новые данные сохраняют набираемый title, layout, версию и Undo. Отзыв скрывает
затронутый источник. Сбой соединения скрывает данные и запускает восстановление.
Events не требует OS permission. Studio по-прежнему использует явный Refresh.

Первые 4 новые PostgreSQL теста PASS: late commit/replay, current rights/interests,
preferences/revocation/restoration, cursor expiry/session binding/bounded scan,
request actor isolation. Первый полный прогон:144 PASS/2 FAIL — обновлено старое
ожидание outbox после добавления grant hints и добавлено обязательное описание
nullable event_name. Повтор этих областей:36 PASS. Финальные CI/браузер/L1 впереди.

Короткий L1 rehearsal:100/100 rendered, p95 2441ms, p99 2647ms, max2681ms,
без HTTP ошибок. Это 60s проверка стенда; не полный15min результат.
