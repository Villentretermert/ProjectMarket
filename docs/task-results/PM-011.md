# PM-011 · Python SDK и независимые боты

22 октября 2026 · завершено после локальной и CI-проверки.

SDK проверяет wire contract, ограничивает JSON, сохраняет тело при retry, запрещает redirects ключа, различает API/transport/protocol errors. Каталог имеет durable inbox и уникальный demo ledger; RSS/Atom публикует пять заголовков/ссылок и chart текущего окна. Два отдельных процесса используют только HTTP и разные operational keys. SQLite — собственное состояние бота, не БД платформы.

## Компоненты и ограничения

`marketob_sdk.client` — transport/auth/typed contract; `marketob_bots.state` — outbound/inbox/demo_effects; catalog/news — доменная логика; `scripts.pilot_bots` — owner HTTP setup; `scripts.smoke_bots` — проверка отдельных процессов и контейнеров. `deploy/Dockerfile.bot` не содержит API/psycopg/test framework.

Нет реальных покупок/оплаты. Журнал должен сохраняться и иметь одного writer. Утрата ACKed journal требует восстановления/разбирательства, не слепого повторения внешнего эффекта. HTTPS для внешнего API; локальный Compose HTTP не является production network isolation. RSS источник настраиваемый, live NASA проверен HTTP200, XML RSS10items; тестовый сценарий использует synthetic fixture.

Web пока demo, Android и cloud отложены. Локального Docker нет; контейнеры проверены в Linux CI.
