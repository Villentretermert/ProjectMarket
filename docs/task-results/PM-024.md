9 ноября: [чистый запуск schema-20261109](PM-024-clean-delivery-20261109.md) выполнен на отдельной БД: 5 UI checks, реальная confirmed-заявка Docker-бота. Полная приёмка открыта.

## 8 ноября · видеодемонстрация My Space

Передан [ролик 76 секунд и инструкция повторения](../demos/my-space-20261108/README.md)
по S01/S07/S08/S09. Отдельный B2C аккаунт получил доступ к двум закрытым каналам,
добавил их в избранное, собрал товар и новость, изменил вид товара, порядок и применил
Undo. Заявка прошла настоящий API и была подтверждена независимым Python-ботом.
Пять групп проверок прошли, page errors — 0, SQL подтвердил ровно одну заявку
`confirmed`. Снимки и кадры записи просмотрены. Данные только синтетические.

`scripts/record_demo.py` повторно использует DockerLab/Lab и подготовку pilot_bots;
`apps/client/record-demo.mjs` выполняет UI-действия, подсвечивает реальные кнопки,
добавляет учебные титры и пишет WebM. Секреты передаются браузеру через stdin,
вход выполняется до открытия записываемой страницы. Ответы HTTP не подменяются.
API — образ 68958f1, БД — отдельный том; Docker-ресурсы и процесс бота удалены
в finally. Рабочая поставка и пользовательские данные не обновлялись.

Первый native-запуск не получил доступ к dev PostgreSQL; итоговая запись выполнена
на изолированной Docker-копии. При подготовке исправлено ожидание ответа выдачи
доступа: фактический HTTP 204. Ruff/format, mypy по 112 файлам и синтаксис JavaScript
прошли. Сценарий не меняет runtime-код приложения.

Личная приёмка владельцем, Android, L2 и оставшиеся release gates не засчитываются
этой записью. PM-024 и SR-2026-10-25 открыты, 19/24, G05 ещё не наступила.

## 24 октября · инструкция передачи

24 октября 2026 · **in_progress (подготовка)**. D44 разрешает независимую
документацию при незавершённых PM-019/020/022/023 и G05. Полная задача не принята.

Подготовлена [единая инструкция](../setup/PILOT_HANDOFF.md) для B2C, B2B,
разработчика бота и оператора: текущий URL, роли, вход, запуск двух Python-ботов,
проверка двумя аккаунтами, ссылки на API, восстановление и известные ограничения.
Документ явно различает работающий Docker `6b3ffb5` и исправления candidate PM-023.
Обновлены README, план и связанная issue.

Команды сверены с CLI `scripts.pilot_bots`, `marketob_bots.news/catalog` и
существующими проверенными runbooks. Браузерные 48 PASS относятся к PM-023,
а не к ручной приёмке этой инструкции владельцем. На рабочем пилоте эта подготовка
не создаёт аккаунты/ботов и не меняет образы. Локальные ссылки проверяет
`scripts/validate_requirements.py`.

APK/AAB, реальный виджет, Play, Google/Firebase, полный L2, G05, финальная
security/privacy-приёмка и релизный архив ещё не готовы. Release candidate не
объявлен. После снятия соответствующих отсрочек нужна полная матрица Web/Android,
чистая установка и приёмка владельцем, затем G06 после 24 завершённых задач.
