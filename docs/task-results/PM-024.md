# PM-024 · подготовка передачи локального пилота

24 октября 2026 · **in_progress (подготовка)**. D44 разрешает независимую
документацию при незавершённых PM-019/020/022/023 и G05. Полная задача не принята.

Подготовлена [единая инструкция](../setup/PILOT_HANDOFF.md) для B2C, B2B,
разработчика бота и оператора: текущий URL, роли, вход, запуск двух Python-ботов,
проверка двумя аккаунтами, ссылки на API, восстановление и известные ограничения.
Документ явно различает работающий Docker `6b3ffb5` и исправления candidate PM-023.
Обновлены README, план и связанная issue.

Команды сверены с CLI `scripts.pilot_bots`, `marketob_bots.news/catalog` и
существующими проверенными runbooks. Браузерные 48 PASS относятся к PM-023,
а не к ручной приёмке этой инструкции владельцем. На рабочем пилоте эта подготовка
не создаёт аккаунты/ботов и не меняет образы. Локальные ссылки проверяет
`scripts/validate_requirements.py`.

APK/AAB, реальный виджет, Play, Google/Firebase, полный L2, G05, финальная
security/privacy-приёмка и релизный архив ещё не готовы. Release candidate не
объявлен. После снятия соответствующих отсрочек нужна полная матрица Web/Android,
чистая установка и приёмка владельцем, затем G06 после 24 завершённых задач.

остаётся открытой. Счётчик 19/24.
