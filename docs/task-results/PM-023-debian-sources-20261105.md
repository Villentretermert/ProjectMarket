# PM-023 · комплект исходных пакетов Debian

5 ноября 2026. Для образов API, бота и БД поставки 68958f1 собран локальный комплект исходников Debian и PostgreSQL Global Development Group. Все 95 сочетаний имени и версии связаны с установленными пакетами. Реестр содержит 350 таких записей, из них 106 в API, 97 в боте и 147 в БД. Две разные редакции cyrus-sasl2 учтены отдельно. [Реестр и инструкция](../../third_party/debian-68958f1/README.md).

## Происхождение пакетов

| Подписанный индекс | Выбранные версии |
| --- | ---: |
| Debian Bookworm main | 86 |
| Debian Bookworm security | 6 |
| PGDG Bookworm | 2 |
| Исторический Debian Security от 22 сентября 2026 | 1 |

Исторический индекс содержит нужную версию tzdata 2026c-0+deb12u1. Два публичных ключевых кольца APT взяты из образа API, привязанного к инвентаризации по SHA-256. gpgv проверил восемь подписей четырёх файлов InRelease. В репозиторий включены публичные ключи, подписанные метаданные и три небольших индекса. Основной индекс Bookworm сборщик получает по хешу. При проверке готового tar все четыре индекса доступны офлайн. [Ключи архива Debian](https://ftp-master.debian.org/keys.html) · [Снимок Debian Security](https://snapshot.debian.org/archive/debian-security/20260922T115254Z/).

Сборщик сопоставляет SHA-256 и размер каждого Sources с подписанным InRelease, затем проверяет имя, версию, каталог и список файлов каждой записи. Для каждого из 95 дескрипторов проверены его собственные имя пакета, версия и полный список файлов, включая патчи и upstream-подписи, перечисленные в дескрипторе. Байты загружаются во временный файл. В кеш попадает файл, прошедший проверку размера и SHA-256. [Сборщик](../../scripts/debian_sources.py).

## Результат проверки

В локальном архиве `.local/pm023/debian/debian-source-kit-68958f1.tar` находятся 304 файла пакетов и 11 файлов метаданных. Размер 549 560 320 байт. Контрольная сумма SHA-256 `d3393b02aa53dd684280ef87ea9a91b10da2f991aa4ec75eab1ce4d427f96ae7`. Комплект прошёл повторную проверку с пустым кешем без обращения к сети. Проверка подписанных индексов отдельно прошла с загрузкой основного индекса в чистый кеш.

В одноразовом Linux-контейнере dpkg-source распаковал все 95 исходных пакетов, включая применение Debian-патчей. У всех 95 версия из debian/changelog совпала с версией в образах. Проверены все встречающиеся форматы, в том числе 77 пакетов quilt, 17 native и один формата 1.0. Подлинность исходных материалов проверена через подписи репозиториев и контрольные суммы. Сборка и сравнение бинарников остаются отдельным этапом.

Семь тестов проверяют сохранение обеих версий пакета между образами, Debian epoch, обязательное присутствие патча, целостность кеша и отказ при неполном или изменённом tar. CI проверяет принадлежность всех 95 версий подписанным индексам на Windows и Ubuntu.

Первый CI обнаружил нестабильность теста подписанного курсора. При исходном первом символе x тест отправлял корректный курсор. Исправленный тест гарантированно меняет первый символ подписи. [Первый прогон](https://github.com/Villentretermert/ProjectMarket/actions/runs/41933146055).

На коммите b810c17 прошли 4 задания CI, 284 различных Python-теста, 54 сценария Chromium и проверка Docker с HTTPS/HTTP2 и восстановлением БД. [CI 41933635979](https://github.com/Villentretermert/ProjectMarket/actions/runs/41933635979). В Ubuntu прошли 174 unit-теста, в Windows 172 с двумя пропусками для Linux. Интеграция с PostgreSQL добавила 110 тестов. На обеих ОС CI сверил 95 версий и 304 записи файлов с подписанными индексами. Локально прошли семь тестов сборщика, Ruff, форматирование и mypy по 107 файлам.

PM-023 открыта. Для следующего этапа нужны воспроизводимая процедура замены или перелинковки применимых библиотек поставки и проверка способа передачи материалов получателю.
