# PM-023-R1 · Привязка материалов к schema-20261109

Выполнена первая из [трёх подзадач поставки](../follow-ups/DELIVERY-2026-11-09.md).
API и bot проверены по immutable image IDs, DB/proxy сохранили прежние IDs.
Полная PM-023 остаётся открытой; счётчик 19/24.

## Доказательства

- [Новый inventory](../../third_party/schema-20261109/inventory.json): 584 записи
  о компонентах, 259 уникальных текстов. Повторное извлечение из четырёх образов
  дало тот же архив текстов, component metadata и начальные 32 notice gaps,
  что исходный реестр 68958f1.
- [Binding](../../third_party/schema-20261109/binding.json) связывает новые IDs,
  исходный commit `896449bde9cdec4cea9f7ce29eba6910285da30e`, исторические материалы
  и текущий реестр через SHA-256. Расширенные native/crate материалы сохраняют
  546 уникальных текстов; их исторические image IDs не переписаны.
- Установленные собственные исходники и LICENSE/NOTICE сверены с Git. Для
  текстовых файлов явно нормализованы CRLF/LF; бинарные файлы сравниваются точно.
  Сгенерированный pip launcher API учтён отдельно, не объявлен исходным файлом Git.
- Native-файлы пяти wheels API и rpds-py бота совпали с прежними source evidence.
  Проверка не опирается только на одинаковые версии пакетов.

## Проверка

`scripts.release_binding` собирает доказательства в read-only контейнерах без
сети и проверяет сохранённый binding. 10 новых проверок охватывают реальный
реестр и отказы при изменении компонентов, notices, gaps, роли, image ID,
native bytes, собственного кода, launcher и счётчика.

25 focused tests (10 binding + 15 delivery), Ruff и mypy119 — PASS.
Первый запуск pytest в sandbox не создал системный temp; повтор с отдельным
`.local/test-release-r1` прошёл. CI checkout получает историю Git для проверки
установленного исходного коммита; результат CI будет добавлен по окончании блока.

## Граница результата

Это инженерная привязка собранных материалов, а не заявление о полной готовности
распространения. Семь групп `open_items` из исторического recipe сохранены.
Полная пересборка всех компонентов, недостающие source/build inputs, attribution,
другие платформы и внешняя приёмка остаются открытыми. Новые source recipe/archive
будут подготовлены следующим пунктом, PM-023-R2. Рабочий пилот не перезапускался.
