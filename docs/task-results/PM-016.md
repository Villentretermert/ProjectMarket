# PM-016 · My Space

Implementation is in final verification; task remains open until final CI evidence.

## Delivered

English My Space opens after login. Create/select/delete own pages, combine blocks
from saved readable channels, change theme/density/order and compatible visualization.
Autosave shows Saved/Saving/Not saved; Undo writes a new version. Preview uses real
authorized data and sends confirmed purchase requests to the original bot.

Personal layout persists independently of B2B definitions and source records. New
sources need current rights; revoked/deleted/unpublished blocks become unavailable
without affecting unrelated blocks. Source selectors also remove inaccessible titles.
Two clients use optimistic versions; lost replies can be retried without duplication.

## Limits

20 active pages, 50 blocks/page, 20 Undo steps in the current editor. Title saves on
blur/Enter, other controls immediately. No cross-device Undo history or automatic
conflict merge. Pending edits survive visibility transitions in memory, not tab closure.
Refresh/navigation/visibility return revalidates sources; idle updates are PM-018.
Sharing is PM-017. Browser contexts simulate another client; no physical Android
device or APK was tested. Docker validation runs in Linux CI, not this local machine.

The implementation follows the announced [design](../design/MY_SPACE.md); density
controls supported spacing, not arbitrary pixel dimensions. [Guide](../setup/MY_SPACE.md),
[API](../api/PERSONAL_PAGES.md), [ADR](../adr/0011-personal-pages.md).
