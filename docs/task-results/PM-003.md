# PM-003 — результаты UX и дизайна

Дата: 21 октября 2026. Статус: **done**, задача дизайна. Продуктовый API и реальные аккаунты отсутствуют. Выполнено 3/4 задач до G01.

## Результат

Создан [интерактивный прототип](../../design/prototype/index.html), [сценарии и токены](../DESIGN.md). Channels, каталог, новости, график/таблица, заявки, B2B Studio, My Space, импорт, локальный вход и HTML-макет виджета работают на английском с явной отметкой demo. Короткие комментарии в JS объясняют границы демонстрации. HTML/CSS/JS выбран согласно ADR-0001; проверка контраста написана на Python.

## Проверки

| Проверка | Фактический результат |
|---|---|
| Desktop 1440 px: B2B create → first data → publish | PASS, до данных Publish disabled; placeholder скрывается; опубликованная preview-страница открывается |
| Mobile 360 px: тот же B2B путь | PASS, одна колонка, Alice показана владельцем |
| Desktop и mobile: избранное/заявка | PASS, Saved меняется, Request sent не означает оплату |
| Повторное действие при Unknown | PASS, View request сохраняет статус и фокусирует существующую заявку |
| Desktop и mobile: композиция/импорт | PASS, добавление/перестановка, тема Ink, код → preview → Carol; private data и timestamp отсутствуют |
| Неверный код | PASS, ошибка Code not found без импорта |
| Loading / empty / error / revoked / missing / unsupported | PASS, заголовки состояний проверены в DOM |
| Offline | PASS, отметка устаревших данных и disabled Send request |
| Widget public/private | PASS только HTML-макета; private не содержит заголовков новостей |
| Локальный вход | PASS макета, поля readonly; реальная аутентификация не имитируется как готовая |
| Клавиатура | PASS Skip → main на 1440 px; Skip → sidebar на mobile; подписанные формы, focus при навигации |
| Mobile 360 px и каталог 320 px | PASS, scrollWidth = clientWidth, на проверенном каталоге видимые основные controls не меньше 44 px |
| Контраст | PASS 12 пар; минимум обычного проверенного текста 4.92:1, focus 4.78:1; `python scripts/check_design.py` |

Во время проверки исправлены повторная отправка при Unknown, показ времени закрытого источника после импорта, роли Alice/Carol, мобильные размеры ссылок, экранирование заголовка канала и Skip на desktop/mobile. Проверки выполнялись в браузере; это не автоматизированный e2e набор продуктового клиента.

## Ограничения

Прототип хранит всё в памяти; имитация статусов не доказывает сетевые гарантии. Нет реальных платежей, приватных данных, ключей, сессий, публичных share-кодов и native widget. Реальные права, долговечность заявок и кеш проверяются при реализации. Android-сборка и устройство отложены владельцем. Screen reader, полный аудит доступности и все размеры всех экранов не заявляются проверенными. Детали stale item / unavailable product задаёт API и продуктовый клиент.
