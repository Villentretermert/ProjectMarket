# PM-023 · замена C-драйвера получателем

7 ноября 2026. Пересобраны оба расширения psycopg-c 3.3.6 из исходного архива,
привязанного к uv.lock. В C-код добавлена помеченная функция с тестовой меткой.
Производный API-образ загрузил её из обоих расширений и прошёл все 13 групп
существующей проверки TLS, транзакций, пулов и отмены запросов.

## Реализация

- `scripts/replace_psycopg.py` проверяет исходник, сохраняет изменённое дерево,
  передаёт ограниченный tar-контекст Docker и сопоставляет baseline/candidate.
- `deploy/replacement/Dockerfile` компилирует wheel в отдельном build stage.
  Runtime получает обновлённый venv. Компилятор и установщик остаются в builder.
- `scripts/smoke_psycopg.py` выполняет настоящие операции через классы
  Database/Pools приложения на одноразовом PostgreSQL с TLS.
- CI повторяет сборку из проверяемого загрузкой sdist и выводит результат.
  Время Docker job увеличено до 20 минут, чтобы включить компиляцию.

Сборка обнаружила особенность COPY. Каталоги объединяются, поэтому прежний
`uv_build.json` сохранялся после переустановки wheel в builder. Финальный рецепт
удаляет два каталога старого драйвера перед копированием venv. Сравнение прочих
файлов site-packages после этой поправки прошло. Контекст отправляется как
GNU tar, который Docker распознаёт при передаче через stdin из Windows.

## Границы результата и дальнейшая работа

Проверена замена psycopg-c в Linux amd64 API. Сборка использует сеть и
build-пакеты из APT. Полное воспроизведение прежнего wheel, пересборка остальных
native-компонентов и готовность всего пакета к внешней передаче остаются
отдельными пунктами. Производный образ используется только для этой проверки.

Следующий шаг — собрать единый передаваемый комплект исходников, уведомлений,
инструкций и проверяемый манифест файлов. В нём явно перечислить оставшиеся
пробелы Alpine/встроенных компонентов. PM-023 остаётся открытой, готово 19/24.
Android, облако и полный L2 отложены владельцем.
