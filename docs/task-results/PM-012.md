# PM-012 · полный backend-цикл и восстановление

22 октября 2026 · в работе, приёмка после всех измерений и CI.

## Что добавлено

Изолированный PostgreSQL lab и реальные API/maintenance/bot процессы. Четыре принудительные остановки бота вокруг durable inbox, ACK и результата; API restart после каждой. Concurrent duplicate, отказ outbox transaction, key revocation, private reads, maintenance restart. Отдельный paced workload с отключёнными retry и полной сверкой accepted receipt/outbox после рестарта.

[Воспроизведение](../setup/BACKEND_LAB.md). Компоненты: `scripts/backend_lab.py`, `fault_bot.py`, `smoke_backend.py`, `load_backend.py`. Fault switches отсутствуют в production API и bot images.

## Границы

Тестовый стенд не является готовым UI. SQLite demo ledger моделирует эффект, не реальную оплату. Сохранность после process restart не доказывает disk-loss/backup recovery. Outbox хранится атомарно, доставка в foreground клиент относится к PM-018. Maintenance сейчас обрабатывает retention/timeouts. Полный L2 30 минут/100 активных UI, burst3000 и мониторинг ресурсов относятся к PM-022.

## Проверки

Первый локальный fault run PASS: четыре crash boundaries, пять API restart, maintenance restart, восемь одновременных дублей, один результат/эффект на заявку, private/key denial. Дополнительная HTTP outbox failure и нагрузка проверяются.
