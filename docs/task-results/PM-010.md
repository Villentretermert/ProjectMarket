# PM-010 · заявки, GET, ACK и результаты

22 октября 2026 · завершено после локальных и контейнерных проверок.

## Изменения

Request purchase/quantity=1 создаёт атомарные request/event/outbox. GET читает
без удаления, ACK подтверждает только durable receipt, result сообщает реальный
processing/confirmed/failed. Idempotency действия и per-bot result ID переживают
рестарт; несовместимые повторы отклоняются. Чужой user/bot, поддельная цена,
устаревшая карточка, отключённое действие и недопустимое количество проверяются.

`actions.py` отвечает за API и async long poll. `request_state.py` — проекции,
отзыв, timeout и bounded cleanup. Migration 005 добавляет action_requests,
action_results и ссылку на заявку в outbox. Maintenance сохраняет unknown и
удаляет только terminal старше30 дней; unresolved не теряется. Hooks охватывают
grant, public→selected, account, bot и channel. Порядок блокировок учитывает FK:
organization→bot→channel→request. Внешние эффекты бот обязан делать идемпотентно.

## Ограничения

Доставка outbox в клиент — PM-018. Нет оплаты, корзины, external exactly-once,
операторского интерфейса разрешения unknown и физического стирания аккаунта.

недоступен. Командные роли PM-014 обязательны до внешнего пилота. Android/облако
по-прежнему отложены; локального Docker engine нет.
