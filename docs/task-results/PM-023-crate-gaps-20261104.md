# PM-023 · уведомления для десяти записей Cargo и комплект исходников

4 ноября 2026. Все десять записей, для которых в прошлом сборе отсутствовал
текст уведомления, теперь сопоставлены с материалами конкретной версии. В трёх
Cargo.lock таких записей с материалами стало 450 из 450. Это охват исходных
пакетов. Состав кода, вошедшего в каждый Linux-бинарник, требует отдельной
проверки. [Набор и команды воспроизведения](../../third_party/68958f1-crate-notices/README.md).

## Как установлено соответствие

| Пакеты | Найденные материалы |
| --- | --- |
| Три версии r-efi | Полный AUTHORS из каждого архива содержит условия использования, владельцев авторских прав и авторов |
| Два пакета WinAPI 0.4.0 | В каждом архиве сохранены заголовки build.rs и src/lib.rs с авторством, годами и условиями |
| anes 0.1.6 | Раздел License исходного README и два файла лицензий из коммита, записанного при упаковке crate |
| wasip2 и wit-bindgen-rt | Из указанного в каждом crate коммита получены MIT, Apache-2.0 и Apache-2.0 с LLVM exception |
| difflib 0.4.0 | LICENSE из дерева, в котором побайтно совпадают Cargo.toml.orig и все шесть упакованных Rust-файлов |
| rustls-platform-verifier-android 0.1.1 | В коммите выпуска совпали Cargo.toml.orig и src/lib.rs. Ссылки на лицензии в каталоге пакета ведут к двум сохранённым корневым текстам |

Для difflib сверены содержимое и относительные пути, включая пример и тест.
Для Android-пакета сравнение покрывает Rust-обёртку. Происхождение вложенного
AAR и атрибуция библиотек импорта в WinAPI остаются отдельными вопросами.
[Дерево difflib](https://github.com/DimaKudosh/difflib/tree/f035fb8e656f27119e23eca9d5b996df14f3885e) ·
[Исходники Android-пакета](https://github.com/rustls/rustls-platform-verifier/tree/da3d9c36f48fb9f8f97e94f132fdab67ab0fc75b/android-release-support).

## Что передавать

Для уведомлений нужны базовый архив из 539 текстов и небольшое дополнение.
В дополнении 19 ссылок ведут к 12 различным текстам, из которых семь добавляются
впервые. Получатель получает 546 разных текстов. Оба реестра связаны хешем
базового inventory. [Базовый набор](../../third_party/68958f1-native/README.md) ·
[Дополнение](../../third_party/68958f1-crate-notices/README.md).

Для исходников собран локальный архив `.local/pm023/crate-review/embedded-source-inputs.tar.gz`.
Он содержит 482 файла, в том числе 6 Python sdists, 450 архивов crate и 26
upstream-файлов с уведомлениями и подтверждениями происхождения. Размер
78 719 279 байт, SHA-256
`983b9cf9026864e4bc5cd17e6a76ce1327f1d1f4aac7c81e1ae7343c53aa71d4`.
После упаковки проверены точный состав и содержимое всех 482 файлов. Для
повторной сборки достаточно опубликованной команды и свежего каталога кеша.

## Проверки

С пустым кешем скачаны и проверены все 30 входных файлов этого дополнения.
Отдельно собран общий архив с ранее проверенными исходниками. Прошли 70
проверок сборщиков уведомлений, Ruff, форматирование и mypy по 105 файлам.
Тесты ловят неверный commit, пропущенный Rust-файл, подменённый путь или
отличающиеся байты upstream. CI проверяет сохранённые архивы на обеих ОС и
скачивает входные файлы дополнения в Ubuntu.

Все четыре задания CI для fdebed8 прошли. Ubuntu выполнил 167 unit-тестов
и повторил загрузку и сверку входных файлов. Windows выполнил 165 тестов с двумя
пропусками для Linux. PostgreSQL выполнил 110 интеграционных тестов с одним
предупреждением. Итого 277 различных Python-тестов и 54 сценария Chromium.
Прошли проверки HTTPS/HTTP2, резервного копирования и восстановления. [Проверка в GitHub](https://github.com/Villentretermert/ProjectMarket/actions/runs/41749693035).
