# PM-015 · Channels and account favorites

Accepted 22 October 2026. Product commit `70d31e0`; [CI 39854053654](https://github.com/Villentretermert/ProjectMarket/actions/runs/39854053654) on `aa9e792` passed all four jobs.

## Delivered

English Channels now opens same-server links/slugs, allows public preview and returns
to the original channel after login or registration. Add/remove favorites persists in
the account; sidebar and Channels use the same manually ordered list. Search filters
titles without changing order. Move up/down saves across sessions. New compares the
published template and data revisions with the exact rendered snapshot.

Current permissions are checked on every list, read, save and seen update. Revoked,
unpublished or deleted references show Channel unavailable without private metadata.
Removal never deletes the publisher's channel. No source-content browser cache is added.

## Limits and design

The implemented screen matches the announced manual-order wireframe. Up to 100 saved
channels; New is not an exact unread-article count. Remote changes need navigation or
Refresh until PM-018. Unknown private links show generic access guidance and do not
send unsolicited access-request messages. Android/cloud remain deferred.
