# PM-013 · Working Web client

Accepted on 22 October 2026. Code commit `79a3f979`; [CI 39846617703](https://github.com/Villentretermert/ProjectMarket/actions/runs/39846617703) passed all four jobs (Ubuntu, Windows, PostgreSQL/Chromium and Docker).

## What changed

The API wheel serves an English HTML/CSS/ES-module client at `/app/`, with no separate
frontend server or build. Layout follows PM-003: channel rail, content area and
My Space/Channels/Studio navigation. PM-013 connects local login, channel reads,
news/product/chart rendering and real request statuses. Studio and the personal page
editor remain clearly marked until PM-014/016; they are not simulated persistence.

`web/api.js` owns cookie/CSRF transport; `dom.js` creates safe text DOM; `render.js`
maps allowlisted blocks to article/list/card/chart/table; `actions.js` confirms one
unit and recovers the same request after an uncertain POST. `app.js` handles navigation,
session lifecycle, loading/offline/error and permission failure. `web_routes.py`
packages explicit assets with CSP, no-store, no-referrer and nosniff.

G03 default views are applied to newly provisioned bot pages. The configurable RSS
default is BBC World; titles, dates and source links only. A live fetch on 22 October
returned 29,895 bytes and 39 valid entries. Automated browser screenshots deliberately
use the bundled synthetic feed for reproducibility, not current BBC stories.

## Limits

Refresh is manual until PM-018. No persistent source-content cache, images, payment,
Android acceptance or cloud identity. An unresolved creation can be recovered only
while its tab request reference remains. The test network errors are deliberate
browser interception; backend outage/revocation behavior is covered in PM-006–012.
