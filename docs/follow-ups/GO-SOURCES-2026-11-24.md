# PM-023-GO · исходные материалы Go

24 ноября 2026 · P1 · часть PM-023 / GitHub #28. После PM-023-CPY.

Цель: передать точные исходные входы Go для Caddy и gosu в schema-20261109.
Счётчик полных задач 19/24; прежние отсрочки сохранены.

1. Сверить бинарники двух runtime images с сохранёнными builder images.
2. Сохранить go.mod/go.sum, main и build metadata; повторить go mod verify без сети.
3. Собрать все входы go.sum, исходники Go 1.26.10 и gosu 1.19.
4. Проверить SHA-256/Go h1, исходные тексты/версии и полный охват; подготовить
   автономный Python verifier, отрицательные тесты и Windows/Linux проверки.
5. Записать результат, инструкцию, CHANGELOG/STATUS и GitHub; выполнить CI.

Приёмка: оба immutable image IDs учтены; отсутствующие/подменённые входы
отвергаются; самостоятельная проверка не требует сети, Git или Docker;
повторный сбор на обеих ОС даёт один manifest. Большие архивы локальны.

Граница: это source supplement, не полный offline build или пересборка
самого компилятора. Bootstrap, native graph, остальные gaps и полная приёмка
остаются открытыми. Исторические архивы и работающие контейнеры не заменяются.
