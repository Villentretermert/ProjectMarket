# PM-023-ALPATTR · атрибуция четырёх Alpine-пакетов

24 ноября 2026 · P1 · PM-023 / GitHub #28 · после PM-023-GOBUILD.

1. Сопоставить четыре пакета с текущим proxy image и точными aports revisions.
2. Проверить заголовки исходников, upstream notices и общие лицензии репозитория.
3. Сохранить подтверждённые тексты и их область действия отдельным дополнением.
4. Проверить целостность/негативные случаи, добавить CI, инструкцию и отчёт.

Приёмка: по каждому пакету есть проверяемое решение с exact source evidence.
Отсутствие notice не заменяется выдуманным copyright; maintainer/commit author
не объявляется правообладателем. Оставшаяся неопределённость сохраняется явно.
Исторические inventories/kits и рабочий runtime не меняются. Полная PM-023
открыта, 19/24; Android/облако/L2 и личная приёмка отложены.
