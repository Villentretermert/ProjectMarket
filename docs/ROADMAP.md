Версия 0.4 · 22 октября 2026 · ответы Q01–Q17 учтены; пилот на локальном компьютере. **24 задачи пилота + 4 задачи развития.** PM-001–012 завершены; локальные identity, registry и ingestion реализованы. G02 закрыта после 12 ответов; PM-009–012 разрешены.

## Как читать и запускать

Команда «Сделай PM-013» однозначно указывает на файл задачи и GitHub Issue. Сначала читается [регламент](WORKING_AGREEMENT.md). Задача содержит цель, объём, порядок, зависимости, ожидаемый результат и проверки. Фактические результаты записываются по завершении, а не заранее.

**P0:** обязательно для связного пилота. **P1:** обязательно до внешнего пилота, после основного пути. **P2:** развитие после пилота. `ready` означает возможность начать, а не завершённость. Зависимости и контрольные точки имеют приоритет над номером; внутри этапа независимые задачи можно переставить по запросу. Сроки не обещаны до технической проверки PM-002.
