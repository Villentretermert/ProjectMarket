# Share / Import · локальный Web

1. Откройте сохранённую My Space, дождитесь Saved и нажмите Share.
2. Выберите срок: 30 days, 7 days или Never; Create link.
3. Copy link / Copy code передаёт оформление, название и ссылки на источники.
   Аккаунты, полномочия и содержимое источников в шаблон не включаются.
4. Получатель открывает ссылку либо Import template и вставляет код. Вход/регистрация
   сохраняют назначение ссылки. Preview template показывает виды и доступность блоков.
5. Import as new page создаёт независимую страницу с суффиксом (copy). Недоступные
   блоки сохраняют места. Разрешение выдаётся отдельно владельцем канала.

При потерянном ответе Retry create link / повтор Import as new page использует тот же
идентификатор; повторная страница не создаётся. Закрытие диалога после неясного результата:
проверьте список ссылок/страниц перед новым созданием.

В Share отображаются активные ссылки и кнопка Revoke. Отзыв/истечение запрещает новые
импорты; предыдущие копии остаются. Удаление исходной личной страницы отзывает её ссылки.
Новые правки автора требуют новой ссылки. Общие лимиты: 20 страниц, 50 блоков, 20
активных ссылок на одну страницу.

Локальный адрес 127.0.0.1 доступен только на этом компьютере. Для друга на другом
устройстве понадобится отдельно настроенный доступ к тому же серверу; облако и туннель
эта задача не разворачивает. Google/Firebase и Android остаются отложенными.
