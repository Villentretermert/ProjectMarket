# My Space · локальное использование

Запустите API и ботов по [Web-инструкции](WEB.md). Войдите в приложение: первым
откроется My Space. Через Channels сохраните доступные каналы в избранное.

1. Нажмите Create My Space или New page и задайте название.
2. Выберите Source channel, затем Block to add и нажмите Add block.
3. Добавьте блок другого канала. Меняйте порядок кнопками Move up/down,
   представление блока, Theme и Density. Изменения сохраняются автоматически.
4. Название сохраняется после Enter или выхода из поля. Дождитесь Saved · vN.
5. Undo отменяет последнее сохранённое изменение новой версией. Доступны до
   20 шагов в текущем редакторе; после нового входа история Undo не восстанавливается.
6. Preview скрывает редактирование. Request purchase подтверждает одну единицу,
   отправляет заявку исходному боту и показывает статус; деньги не списываются.

Layout хранится в аккаунте и восстанавливается в другой браузерной сессии. Можно
создать до 20 страниц с 50 блоками каждая. Density задаёт поддерживаемую плотность,
произвольного изменения пиксельных размеров нет. Товары: Compact list/Card;
новости: Expanded/Compact; числовые графики: Line/Bars/Table.

При Save not confirmed нажмите Retry save: повтор не создаёт новую версию, если
сервер уже принял изменение. При конфликте другого клиента локальные поля остаются
видны; Reload saved загрузит серверную версию, отбросив неподтверждённую правку.
Не закрывайте вкладку с неподтверждёнными изменениями: они хранятся только в памяти,
не на диске. Навигация предупреждает о несохранённом состоянии.

Refresh заново проверяет права и читает актуальные источники. Отзыв доступа,
удаление данных или блока публикации дают Source unavailable. Другие блоки работают;
недоступный блок можно переставить/удалить. Изменение My Space не меняет B2B канал.
Автоматические обновления при бездействии — PM-018; отправка шаблона другу — PM-017.
Снимки [приёмки](../task-results/PM-016.md) используют синтетические данные.
