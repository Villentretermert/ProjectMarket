# ADR-0005 — Локальная identity и доступ

22 октября 2026 · PM-006. Развивает контракт PM-004 и локальный режим владельца.

Пароли: Argon2id через argon2-cffi 25.1.0, соль и параметры в хеше, rehash при
успешном входе. Сессии: 256 бит случайности, opaque cookie, в PostgreSQL только
SHA-256 verifier. CSRF привязан к текущей сессии; Origin проверяется точно.
Вместо JWT выбрана серверная сессия: logout и деактивация действуют сразу без
дополнительного списка отозванных JWT. Google и native storage пока не доказаны.

Каждый пользователь может включить личный B2B-профиль: сервер создаёт организацию
и owner membership. Это один владелец, без командных ролей/приглашений; исходный
пилот не требует командного администрирования. Глобальная роль от клиента не
принимается, grants дают только чтение. Username lookup требует B2B-сессию.
Email-приглашения и email recovery отсутствуют в локальном режиме.

Доступ выделен в `channel_access` отдельно от будущего контента. В PM-006 его
проверяют реальные SQL/HTTP-тесты на synthetic fixtures; каналы создаются следующими
задачами. Общая политика вызывается внутри транзакции операции. Отзыв grant пишет
outbox; действия/их отмена появятся в PM-010. Логическое удаление аккаунта отзывает
сессии и доступ, убирает пароль/имя и оставляет зарезервированный username/opaque ID;
не выдаётся за физическое стирание исторических данных.

Миграции — короткие SQL-файлы в Python-пакете, единая транзакция, advisory lock и
контроль суммы. Для текущего небольшого SQL-слоя psycopg позволяет явно видеть
границы фиксации и блокировки; ORM не добавлен. Все success-ответы следуют после
commit. Ключ подписи курсоров генерируется при миграции в БД, не зашит в код/env.

Настоящая PostgreSQL 18.6 установлена переносимым архивом EDB под `.local`, не как
служба Windows. Из-за кириллицы в пути initdb использован Windows short path.
Слушает только 127.0.0.1:55432, случайный пароль не публикуется. Docker CI продолжает
проверять PostgreSQL 18.4. Тесты используют отдельную случайную схему и удаляют
только её. Docker локально по-прежнему не установлен.

Источники: [argon2-cffi API](https://argon2-cffi.readthedocs.io/en/stable/api.html),
[psycopg transactions](https://www.psycopg.org/psycopg3/docs/basic/transactions.html),
[PostgreSQL Windows](https://www.postgresql.org/download/windows/).
