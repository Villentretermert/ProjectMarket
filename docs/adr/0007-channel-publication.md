# ADR-0007 · Immutable оформления и живые данные каналов

22 октября 2026 · PM-009 · принято для локального пилота по G02-04/05/07/09.

Черновик хранится отдельно от указателя опубликованной версии. Каждое сохранение
создаёт неизменяемую запись channel_versions. Публикация меняет указатель,
действующий access policy и outbox в одной транзакции. Обновления бота продолжают
менять source_records; read собирает только источники опубликованных блоков.

Альтернатива — копировать данные вместе с макетом — противоречит подтверждённому
живому обновлению. Изменять один макет на месте проще, но это раскрывает черновики
и не обеспечивает воспроизводимое оформление. Поэтому откат копирует старую
опубликованную структуру в новую монотонную версию, сохраняя текущие данные.

channel_access блокируется на время чтения/публикации/ingestion: права, версия и
источники согласованы внутри операции. Долгих внешних вызовов в транзакции нет.
Списки ограничены и используют подписанный fixed scan; версии содержат только
оформление, не исторические payload. Версии пока не очищаются: политика архивов
и физическое стирание уточняются в PM-023.

ETag учитывает аудиторию, структуру и данные. Сначала права, затем условие 304;
HTTP no-store сохраняется. Новый канал по умолчанию Selected users. В пилоте
разрешено только Request purchase, одна единица и без оплаты; action delivery
реализуется следующей PM-010. Командная модель запланирована PM-014 по G02-01.
