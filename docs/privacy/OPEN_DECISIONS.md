# Открытые решения PM-023

24 октября 2026. Вопросы отправлены отдельными карточками. Ответов пока нет;
первый вариант в карточке не является автоматически принятым решением.

## P1 · Состав личного экспорта

Что включать в JSON, скачиваемый пользователем?

- Профиль, избранное, My Space, собственные заявки и event preferences;
  без ключей ботов и чужих частных данных.
- Только профиль, избранное и оформление.

Ответ: **ожидается**. Экспорт не реализован.

## P2 · Удаление аккаунта владельца workspace

Что делать с его workspace и каналами?

- Удалять их с явным предупреждением о последствиях.
- Не разрешать удаление аккаунта, пока у него есть workspace.
- Сначала требовать передачу владения.

Ответ: **ожидается**. Текущий API деактивирует workspace/каналы и сохраняет
исторические записи; это описание существующего поведения, не выбранный вариант.
Передача владения в пилоте пока не реализована.

## P3 · Подтверждение удаления

Как подтверждать удаление после показа последствий?

- Текущий пароль.
- Текущий пароль и ввод `DELETE`.

Ответ: **ожидается**. Новый экран остаётся прототипом; существующий API требует пароль.

## A1 · Исправление отзыва при заполненной очереди

Требуется ответ владельца на реализацию и интеграционную проверку предложения.
