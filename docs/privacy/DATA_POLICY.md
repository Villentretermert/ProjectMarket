# Данные локального пилота · фактическое поведение

24 октября 2026 · PM-023, независимая Web/API-часть. Это техническое описание
текущего кода, не утверждённая политика полного удаления и не декларация
соответствия требованиям магазинов. Ответы D46 реализованы в Web/API; проверки и снимки в
[отчёте](../task-results/PM-023-account-privacy.md).

## Что хранится

| Группа | Данные и границы хранения |
| --- | --- |
| Аккаунт | Username, display name, hash пароля, ID, отметка деактивации. Пароль не хранится открытым. Удаление аккаунта убирает hash и заменяет display name; username/ID остаются. |
| Сессии | Hash токена и срок действия; по умолчанию 24 часа. Logout удаляет текущую сессию; удаление аккаунта — все его сессии. Worker физически удаляет истёкшие сессии после дополнительного дня. |
| B2B | Workspace, membership, grants, боты, hashes credentials, настройки/версии каналов. Регистрационный credential действует 15 минут, рабочий ключ — 90 дней; истечение/отзыв прекращают авторизацию, а не обязательно удаляют запись. |
| Источники ботов | Актуальные source records, revision tombstones и оформление сохраняются отдельно от истории. Удаление страницы делает её недоступной, но не стирает эти данные физически. |
| История приёма | Ingest history и receipts очищаются пакетами после 30 дней. В пределах этого срока повторы защищены квитанциями. |
| Заявки | Request/result, пользователь, товар, входные данные и статус. Терминальные заявки очищаются после 30 дней; незавершённые/unknown не удаляются только по возрасту. |
| Личные страницы | Избранное, порядок, layout/Undo и shared templates со ссылками на источники. Layout не содержит права на источник. При удалении аккаунта собственные favorites, pages и shared templates физически удаляются. Чужие ранее импортированные копии независимы. |
| Доставка | Outbox содержит ссылки/идентификаторы изменений. Доставленный старый prefix очищается после часа; это не предельный срок для недоставленных строк. Cursor истекает через 10 минут, после потери истории требуется resync. |
| Events | Настройки пользователя для каналов. Удаление аккаунта стирает свои preferences сразу; worker очищает legacy metadata и удалённые источники/workspace. Отзыв одного grant сам по себе не означает физического удаления preference. |
| Оператор | Резервные копии БД, приватные env, журналы ботов и CA живут отдельно. Автоматической ротации/удаления backups и сквозного удаления во внешних ботах нет. |

## Деактивация и отзыв

`DELETE /v1/account` требует текущий пароль и точное слово DELETE. Пока есть
активный собственный workspace, сервер возвращает409 и требует передачу
владения действующему Admin. Переданные workspace, боты и каналы продолжают
работать. После удаления сессии, личные grants/memberships, layouts/favorites,
shared links и preferences физически удалены. Собственные outbox hints убираются;
marker заставляет открытых клиентов заново проверить права. Username/ID остаются
зарезервированы, password hash очищен, display_name заменён. Заявки без ACK
отменяются, ACKed незавершённые переходят на сверку; исторические business records
не стираются без учёта retention. Это не полное удаление данных внешних ботов/backups.

Worker раз в минуту пытается удалить до 5 000 preferences и до 5 000 outbox hints
для удалённых сущностей за проход. При сбое БД/другой части обслуживания очистка
может задержаться. Минимальные общие hints `access.revoked`/`source.deleted`
сохраняются до обычной очистки prefix, чтобы открытые клиенты получили отзыв;
пользовательские hints удалённого аккаунта убираются. Чужие события, receipts,
заявки и delivery IDs этой очисткой не меняются.

На каждом чтении сервер проверяет текущие права. Web убирает частные данные при
потере сети/скрытии вкладки и повторно проверяет их при возвращении. Теперь отзыв
источника также закрывает открытое подтверждение покупки с его названием.
Скачанные файлы, снимки экрана и уже переданные внешнему сервису данные таким
действием не отзываются. Постоянного кеша частного содержимого в service worker нет;
вкладка может хранить только ссылки для восстановления незавершённой заявки.

В старой работающей поставке `6b3ffb5` полная очередь может сорвать транзакцию
изменения прав; такой отзыв **не считается состоявшимся**. В candidate PM-023
эта зависимость заменена атомарным marker, вызывающим resync открытых клиентов,
по разрешению D45. [Отчёт исправления](../task-results/PM-023-queue-fix.md) указывает
проверки и статус поставки. Ошибка транзакции в любом случае не считается успехом.

## Экспорт и оставшаяся проверка

[Privacy API](../api/PRIVACY.md) выгружает профиль, Favorites, активные My Space,
метаданные собственных заявок и Events. Секреты/чужие записи/source payloads и
bot summaries исключены. Разделы живые, не point-in-time backup; большие списки
постраничные, браузерный файл до50MiB. Неудачная выгрузка не скачивает частичный файл.

P1–P3 согласованы (D46). Остаются реальный Android/виджет, Google/Firebase,
background push и актуальные правила магазинов при возобновлении этапов.
[Решения](OPEN_DECISIONS.md) и [результаты](../task-results/PM-023-account-privacy.md).
Логи не содержат private payloads или credentials. Рабочая Docker-поставка пока
не обновлена и имеет прежнее поведение; не путать её с проверяемым candidate.
