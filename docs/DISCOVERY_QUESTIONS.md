# Вопросы владельцу

19 октября 2026. Каждый вопрос задаётся отдельно. Варианты в чате — подсказки, а не принятые решения. Можно отвечать по одному, писать свой вариант или «на твоё усмотрение».

## Q01 — Название и ценность

Как назвать приложение и какую главную проблему оно решает для первых пользователей?

**Ответ:** Пилотное название MarkeTOB. Один удобный интерфейс для огромного количества ботов одного клиента.

**Связанные задачи:** PM-001.

## Q02 — Сценарии пилота

Какие сценарии важнее: каталог товаров, новости, аналитика продаж или свои? Выберите первые два.

**Ответ:** Каталог товаров и новости.

**Связанные задачи:** PM-001, PM-003, PM-011.

## Q03 — Платформы

Подтверждаете Android + Web + Docker в пилоте, а iOS и Windows на следующем этапе?

**Ответ:** Android, Web и облачный бэк; iOS и Windows позже.

**Связанные задачи:** PM-001, PM-019, PM-025, PM-027.

## Q04 — Вход

Как входят пользователи: email, Google, Telegram? Нужен ли публичный просмотр без регистрации?

**Ответ:** Через Google.

**Связанные задачи:** PM-006, PM-013.

## Q05 — Типы ботов

Подключаем любые HTTP-сервисы, Telegram-ботов через адаптер или только одну категорию?

**Ответ:** Любые HTTP-сервисы, включая адаптеры Telegram-ботов.

**Связанные задачи:** PM-004, PM-007, PM-011.

## Q06 — B2B onboarding

Кто подключает ботов: приглашённые владельцы, любой пользователь или только после одобрения?

**Ответ:** Любой B2B пользователь самостоятельно.

**Связанные задачи:** PM-006, PM-007, PM-014.

## Q07 — Доступ к страницам

Нужны публичные страницы, непубличные ссылки, закрытые страницы для выбранных пользователей?

**Ответ:** Публичные и закрытые для выбранных пользователей.

**Связанные задачи:** PM-006, PM-009, PM-017.

## Q08 — Блоки

Какие блоки обязательны: новости, товары, таблицы, графики, показатели, формы, действия?

**Ответ:** Текст/новости, карточки товаров, графики.

**Связанные задачи:** PM-003, PM-004, PM-009, PM-016.

## Q09 — Покупка

**Ответ:** Передавать заявку боту и показывать статус.

**Связанные задачи:** PM-010, PM-014, PM-028.

## Q10 — Конструктор

**Ответ:** Добавлять блоки разных каналов, менять порядок, оформление и тип визуализации.

**Связанные задачи:** PM-004, PM-016.

## Q11 — Передача интерфейса

## Уточнение локального этапа, 21 октября 2026

Последний ответ владельца: «пока сделаем на локальном компьютере, без облака». Google/Firebase не требуются для текущего запуска. Вместо Google-пользователей в нагрузочных сценариях используются локальные аккаунты; live SLO сохраняется, background push отложен. См. [LOCAL_MODE.md](requirements/LOCAL_MODE.md). Исторические ответы Q04/Q13 сохранены как направление развития.
