Таймкоды приблизительные: начало каждого поясняющего шага из записи Playwright. Последние секунды файла могут отличаться от времени закрытия браузера.

Изолированная база, четыре товара, тестовая RSS-лента, два настоящих HTTP-бота. Видео показывает успешную заявку; неуспешные сценарии описаны в API и тестах. Экспорт/удаление и операции с ключами показаны как доступные экраны без выполнения удаления или выдачи секрета.

Исходный сценарий расширяет `apps/client/record-demo.mjs` и `scripts/smoke_release.py`. Браузер: Microsoft Edge 158.0.4370.33. Перед финальным дублем исправлены только ожидание загрузки диалога Events и имя кнопки Cancel в сценарии записи. Код продукта не изменялся.

MP4 полностью декодирован FFmpeg без ошибок. Для визуальной проверки извлечены 23 кадра, по одному на главу. `result.json` содержит функциональные проверки и отсутствие page errors. `release.json` фиксирует образы, одну confirmed-заявку и удаление временной среды.
