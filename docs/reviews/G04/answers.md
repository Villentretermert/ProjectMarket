# G04 · разрешение продолжить и рабочие допущения

23 октября 2026 владелец написал «Продолжай» после презентации и 13 отдельных
вопросов. Это явное указание продолжить PM-017–018; отдельных ответов на вопросы
не получено. Следующие пункты — объявленные рабочие допущения, не ответы владельца.

1. Текущий редактор и плотность сохраняются.
2. Лимиты 20 страниц / 50 блоков остаются.
3. Undo: 20 шагов в текущем редакторе.
4. Серверная ссылка/случайный код; сервер должен быть доступен получателю.
5. Срок новой ссылки по умолчанию 30 дней; доступны 7 дней и без срока.
6. Удаление исходной страницы отзывает ссылки; прошлые копии сохраняются.
7. Недоступные блоки сохраняют свои места без данных.
8. Импорт получает суффикс (copy).
9. Снимок immutable; новые правки требуют новой ссылки.
10. Уведомления внутри приложения по умолчанию только для собственных заявок.
11. Новые данные обновляются независимо от текущей правки оформления.
12. Android/USB и облако остаются отложены; лицензии не принимаются.
13. Выполняются PM-017 и PM-018, затем отчёт; PM-019/020 пока не начинаются.
