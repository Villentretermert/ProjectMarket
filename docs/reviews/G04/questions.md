# G04 · отдельные вопросы перед продолжением

Ответы пока не получены. Варианты ниже — предложения, не принятые решения.

1. Подходит ли показанный редактор My Space для пилота: выбор источника, блоков, порядка и вида?
   - Сохранить текущий; упростить редактор перед обменом.
2. Достаточно ли ограничений 20 личных страниц и 50 блоков на каждой для первого пилота?
   - Достаточно; нужны более высокие пределы (укажите какие).
3. Достаточно ли Undo на 20 изменений в текущем открытом редакторе, без истории после нового входа?
   - Достаточно для пилота; нужна история между входами.
4. Для обмена подходит ссылка и случайный код, которые загружают сохранённый шаблон с работающего сервера MarkeTOB?
   - Да, серверный код; сначала нужен автономный файл с оформлением.
5. Какой срок действия подставлять для новой ссылки на шаблон, сохранив ручной отзыв?
   - 30 дней; без срока до отзыва; 7 дней.
6. При удалении автором личной страницы автоматически отзывать все выданные из неё ссылки? Уже импортированные копии сохранятся.
   - Да, отзывать; ссылки живут до отдельного отзыва.
7. Если у друга нет доступа к части источников при импорте, оставлять на их местах Source unavailable?
   - Оставлять места; исключать недоступные блоки из новой страницы.
8. Как называть импортированную страницу по умолчанию?
   - Исходное название с суффиксом (copy); сохранить исходное название.
9. Подходит ли неизменяемый снимок при обмене: последующие правки автора требуют новой ссылки, старый код сохраняет прежнее оформление?
   - Да, отдельный снимок; хочу обновлять шаблон по прежнему коду.
10. Какие уведомления включать по умолчанию внутри открытого приложения? Остальные пользователь сможет выбрать.
   - Только статусы собственных заявок; статусы заявок и новые новости; всё выключено до выбора.
11. Во время редактирования My Space новые данные источников должны обновляться, сохраняя текущую правку оформления и порядок?
   - Да, обновлять данные; отложить данные до завершения редактирования.
12. Android-сборка и USB-проверка пока остаются отложенными?
   - Да, пока только Web; готов вернуться к настройке Android после Web-обмена и обновлений.
13. Подтверждаете следующий шаг PM-017–018: обмен шаблонами, затем обновления и выбранные события, с учётом ответов G04?
   - Да, выполнить обе задачи; сначала только PM-017; сначала скорректировать план.
