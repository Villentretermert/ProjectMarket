# Вопросы после обзора 25 октября 2026

Каждый пункт задаётся отдельной карточкой. Это дополнительный обзор, не закрытие
G05. Android, облако и полный L2 остаются отложенными. Ответы не подставляются
по умолчанию и не меняют ранее согласованные решения до их получения.

1. **S01.** Какой сценарий вы хотите первым пройти лично в локальном пилоте?
   My Space с товарами и новостями / подключение бота в Studio / обмен страницей.
2. **S02.** Нужен ли перед внешним пилотом пошаговый помощник подключения бота в Studio?
   Да / достаточно текущих экранов и инструкции / решить после личной проверки.
3. **S03.** Как удобнее выбирать блоки для My Space?
   Сохранить выбор канала и блока / добавить визуальный каталог блоков / решить после проверки.
4. **S04.** Что показывать рядом с недоступным источником?
   Краткое объяснение и повторную проверку / добавить подсказку, как получить доступ / оставить текущий вид.
5. **S05.** Какая доработка каталога наиболее полезна после текущих обязательных проверок?
   Поиск и фильтры / фотографии товаров / пока достаточно текущего каталога.
6. **S06.** Какую конкретную публичную RSS-ленту общих новостей использовать для следующего примера?
   Укажите URL либо напишите, что пока оставить демонстрационный источник.
7. **S07.** Для ручной проверки внешнего подключения у вас уже есть HTTP-бот?
   Пока использовать наш Python-пример / есть собственный HTTP-сервис / нужен пример Telegram-адаптера.
8. **S08.** Какие события важнее первыми проверить лично?
   Ответы на заявки / новые новости / оба сценария одинаково важны.
9. **S09.** Какой формат инструкции для самостоятельного запуска удобнее?
   Пошаговая инструкция со снимками / короткая видеодемонстрация / достаточно существующего Markdown.
10. **S10.** Какую модель распространения исходного кода вы планируете?
    Пока не определена / открытый код / закрытая коммерческая модель.
    Конкретная лицензия этим ответом автоматически не выбирается.
11. **S11.** Кто будет первым пробовать продукт вместе с вами после завершения обязательных проверок?
    Несколько знакомых B2C пользователей / один B2B партнёр / смешанная небольшая группа.
12. **S12.** Какой следующий шаг предпочитаете после этого обзора?
    Продолжить разбор и обновление зависимостей / сначала пройти локальную демонстрацию / сначала обсудить изменения интерфейса.
