# G02 · отдельные вопросы владельцу

Каждая строка ниже отправляется отдельной карточкой. Это новые вводные для
PM-009–012 и будущего Studio, не повтор вопросов о платформах/Google/Android.

| ID | Вопрос | Варианты / влияние |
|---|---|---|
| G02-01 | Достаточно ли в пилоте одного владельца у каждого B2B workspace? | Один владелец; командные роли нужны до внешнего пилота; командные роли нужны сейчас. PM-006/014 scope |
| G02-02 | Какие товары использовать в первом демонстрационном каталоге? | Электроника; повседневные товары; цифровые продукты (свободный текст также доступен). PM-011 fixtures |
| G02-03 | Откуда брать новости для первого пилотного бота? | Синтетические локальные новости; публичный RSS; собственный HTTP-источник. PM-011 adapter |

| G02-05 | После первой публикации показывать новые данные бота сразу? | Да, данные сразу, оформление отдельно публикует владелец; каждое обновление требует подтверждения. PM-009 semantics |
| G02-06 | Как напоминать владельцу о замене 90-дневного ключа бота? | За 7 дней и при истечении; только при истечении; пока вручную. PM-014 UI |

| G02-10 | Как демонстрационный каталог-бот должен отвечать на заявки? | Автоматически с примерами подтверждения и отказа; ждать ручного решения оператора. PM-011 behaviour |
| G02-11 | Подходит ли история сообщений 7 дней и защита от дублей 30 дней? | Сохранить; история 30 дней; нужен более долгий архив. PM-008/021 retention |
