# Лицензии и подготовка к распространению

3 ноября 2026. D49 фиксирует выбор владельцем Apache License 2.0 для собственного
кода MarkeTOB. Канонические [LICENSE](../../LICENSE) и [NOTICE](../../NOTICE)
скопированы в четыре Python-пакета. Сборки wheel включают оба файла и выражение
`License-Expression: Apache-2.0`. Получатели сторонних компонентов сохраняют
права и обязанности по лицензиям этих компонентов.

## Готовый результат

[Реестр](../../third_party/68958f1/inventory.json) привязан к immutable image IDs
API, бота, PostgreSQL и proxy. [Архив](../../third_party/68958f1/texts.tar.gz)
содержит 259 уникальных текстов. Сохранены их байты, исходные пути и SHA-256.
Debian binary packages сопоставлены с source package/version. Для Alpine
сохранены origin, версия, commit aports и заявленная лицензия.

Для Go проверено совпадение бинарников builder/runtime и module sums с `go.sum`.
`go mod verify` прошёл в обоих builders. Тексты взяты из этих проверенных caches.
Это список модулей бинарника с полными найденными файлами их лицензий,
включая дополнительные notices для исходных поддеревьев модулей.

У `jsonschema_rs` wheel не содержит найденного файла лицензии. Два совпадающих
MIT-текста извлечены из sdist 0.57.1 с SHA-256 из `uv.lock`. Они относятся к
исходному пакету. Отдельная атрибуция всех встроенных Rust crates ещё нужна.

## Следующие действия перед передачей образов

| Пункт | Состояние | Проверяемый результат |
| --- | --- | --- |
| Собственная лицензия | Готово | Apache-2.0 и полные LICENSE/NOTICE в четырёх wheel |
| Извлечение доступных текстов | Готово | 259 текстов, проверенные хеши и ссылки |
| Alpine | Открыто | Тексты из точных исходных версий 32 binary packages, проверка aports patches |
| Встроенный код | Открыто | Rust crates в jsonschema_rs/pydantic-core/rpds-py и C-код в cffi/argon2 проверены по source/build inputs |
| Соответствующие исходники | Открыто | Архивы и patches точных GPL/LGPL/MPL-компонентов, build/relink materials и способ передачи получателю |
| Проверка новых образов | Открыто | Notice/source sidecar связан с новым immutable release и включён в поставку |
| Windows/Android и инструменты разработки | Отдельный охват | Уведомления фактических распространяемых бинарников этих платформ |

Полные исходники системных пакетов в текущий notice archive не входят.
Ссылки на upstream и source versions дают основу для их подготовки, но сами
по себе не заменяют выбранный способ выполнения условий передачи исходников.
Собственная Apache-2.0 также не отменяет проверку условий замены или повторного
связывания LGPL-библиотек в конечной поставке.

## Основания

- [Apache 2.0, разделы 3–4](https://www.apache.org/licenses/LICENSE-2.0)
  описывает патентную лицензию, сохранение лицензии/уведомлений и отметки изменений.
- [Текст LGPL v3 в psycopg 3.3.6](https://github.com/psycopg/psycopg/blob/3.3.6/LICENSE.txt)
  содержит условия для приложения и Combined Work, включая предоставление
  нужных материалов или подходящий механизм совместного использования библиотеки.
- [Debian Policy 12.5](https://www.debian.org/doc/debian-policy/ch-docs.html#copyright-information)
  определяет package copyright и ссылки на общие тексты лицензий. Поэтому
  collection сохраняет и package notices, и `/usr/share/common-licenses`.

Эта запись является инженерным перечнем материалов и открытых проверок.
Полная лицензионная готовность внешней поставки пока не подтверждена.
