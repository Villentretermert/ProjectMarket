# Комплект собранных исходников MarkeTOB

8 ноября 2026. Комплект объединяет материалы для Linux-поставки 68958f1.
В него входят исходники проекта, инструменты проверки, уведомления, три ранее
проверенных набора исходных материалов и изменённый psycopg-c из проверки замены.
Состояние охвата — partial. Оставшиеся пункты перечислены в GAPS.md и манифесте.

## Получатель

Передаются пять файлов из каталога результата.

- marketob-sources-68958f1.tar — основной комплект.
- verify_bundle.py — самостоятельная проверка на Python 3.14, только стандартная библиотека.
- SHA256SUMS — контрольная сумма всего tar.
- receipt.json — размер, сумма, состав, Git revisions, image IDs и открытые пункты.
- README.md — эта инструкция.

Сверьте SHA-256 с опубликованной квитанцией проекта или полученным доверенным
каналом значением. Соседний SHA256SUMS позволяет обнаружить повреждение при
передаче, но сам по себе не подтверждает отправителя. Цифровая подпись комплекта
не создаётся.

Перед распаковкой выполните команду, подставив ожидаемую сумму.

```text
python verify_bundle.py --verify marketob-sources-68958f1.tar --sha256 <64-символьный-SHA256>
```

Git, Docker, доступ к сети и checkout для этой проверки не требуются.
Программа сверяет весь файл, затем читает манифест и последовательно проверяет
имя, тип, размер и SHA-256 каждого члена. Дубли, ссылки, лишние и отсутствующие
члены отвергаются. Файлы из архива при проверке не исполняются и не извлекаются.
Результат integrity=verified означает прохождение проверки байтов. Поле
coverage_state=partial и open_items остаются частью результата.

## Содержимое

| Путь в tar | Назначение |
| --- | --- |
| manifest.json | Состав и SHA-256 каждого вложенного файла, обе Git revisions и четыре image IDs |
| LICENSE, NOTICE | Apache-2.0 и уведомление собственного проекта |
| GAPS.md | Незавершённые пункты подготовки поставки |
| sources/project.tar | Все отслеживаемые файлы точного коммита 68958f1 |
| sources/tooling.tar | Все отслеживаемые файлы коммита сборки комплекта, включая уведомления и инструкции |
| sources/debian.tar | 95 версий исходных пакетов, 304 pool-файла и 11 файлов метаданных |
| sources/alpine.tar.gz | 187 проверенных исходных файлов и рецептов |
| sources/python-rust.tar.gz | 6 Python sdists, 450 crates и 26 upstream-файлов |
| sources/modified-psycopg.tar.gz | Изменённое дерево успешно проверенной пересборки драйвера |

После проверки распакуйте основной tar в отдельный пустой каталог. Git-архивы
project.tar и tooling.tar также извлекайте в разные пустые каталоги. В tooling
находятся third_party/68958f1-native и third_party/68958f1-crate-notices с двумя
архивами 546 различных текстов, их источниками и хешами. Предыдущие наборы
сохранены для проверки цепочки доказательств.

В каталоге tooling можно повторить более глубокие проверки.

```text
python -m scripts.native_notices --verify --output third_party/68958f1-native
python -m scripts.crate_notices
python -m scripts.debian_sources --verify-archive <путь-к-sources/debian.tar>
```

Последняя команда дополнительно требует gpgv и проверяет сохранённые подписи
APT, исходные версии и внутренние файлы Debian. Она работает без сети.
Инструкция замены драйвера находится в tooling/docs/licensing/REPLACING_LIBRARIES.md.
Сборка приложения и драйвера по этим инструкциям требует Docker и build inputs,
часть которых загружается из сети.

## Повторить сборку комплекта

Из чистого tracked checkout выполните команду с четырьмя подготовленными архивами.
Их точные байты закреплены в third_party/delivery-68958f1/recipe.json. Подставьте
свои пути к ранее собранным материалам.

```text
python -m scripts.delivery_bundle --output .local/handover --source debian.tar=<debian-kit> --source alpine.tar.gz=<alpine-inputs> --source python-rust.tar.gz=<python-rust-inputs> --source modified-psycopg.tar.gz=<modified-source>
```

Сборщик берёт проект и инструменты через git archive по конкретным коммитам.
Локальные .env, резервные копии, секреты и выгрузки пользователей не входят в Git
снимки. История Git и данные работающего приложения в комплект не включаются.
Новый tar публикуется только после успешной проверки. Существующий каталог
результата и прежний архив не перезаписываются.

Набор не содержит Docker images или APK. Он подготовлен как единый комплект
имеющихся исходных материалов и инструкций. Полный автономный rebuild и готовность
внешнего пилота остаются в перечне открытых работ.
