## Цель

Согласовать единый версионированный контракт для любого HTTP-бота.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Из проекта API получить OpenAPI и JSON Schema: регистрация/ключи, текст/JSON/event, страницы/блоки, действия, GET событий, ACK и результат, cursors и ошибки. Разделить schema_version, template_version и data_revision. Определить типы news/product/chart, допустимые преобразования, идемпотентность, размеры, хранение и поведение удалённого источника. Дать английские примеры для человека и ИИ.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Спецификация, валидные/невалидные примеры, описание совместимости и ошибок.
