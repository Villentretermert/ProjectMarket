## Изменение текущего объёма по ответу владельца

21 октября 2026 владелец отложил Android-сборку и подключение телефона. Текущая приёмка задачи: Web-клиент и локальная архитектура. Native APK/виджет не засчитываются: их доказательство перенесено в начало PM-019/020; выбор Android-оболочки остаётся открытым. Google/Firebase также отложены. Это изменение объёма, а не утверждение о прохождении первоначальных Android-критериев.

## Цель

Выбрать практически проверенный Web-стек и локальную архитектуру с максимальным использованием Python; сохранить явный gate Android-проверки.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Сравнить Python/Flet и альтернативу для Web/Android на одном экране: карточка товара, новости, график, локальный demo-профиль, deep link, offline-кеш (Google-вход отложен по уточнению владельца). Подготовить границы Android-интеграции; её сборка/доказательство виджета отложены владельцем в PM-019/020. Оценить Web-доступность и размер/запуск клиента. Обосновать нативные компоненты. Зафиксировать модульный backend, PostgreSQL, worker и схему развёртывания.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

ADR со стеком, воспроизводимый spike, результаты на Web и явный статус отложенной Android-проверки, перечень SDK/аккаунтов и версия инструментов.

## Критерии приёмки

- [x] Есть воспроизводимая Web-сборка и сравнение кандидатов. Серверная сессия Python не выдаётся за offline runtime. Решение по Web принято; Android/виджет явно не проверены и оставлены открытыми в ADR и PM-019/020 по ответу владельца.
- [x] Проверки выполнены и их фактические результаты сохранены.
- [x] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [x] Пояснительная записка `docs/task-results/PM-002.md` содержит изменения, ограничения и доказательства.

## Проверка

Восстановление npm-зависимостей из lock; Web build; открытие URL и reload; доступность, offline и локальный профиль. Реальный Google flow отложен: [локальный режим](../requirements/LOCAL_MODE.md).
