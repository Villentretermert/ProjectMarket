## Обязательная отложенная проверка PM-002

Владелец отложил Android-сборку/USB 21 октября 2026. До продуктового переноса завершить native feasibility gate: сборка Capacitor-кандидата, установка, cold start/offline, custom-scheme deep link и настоящий launcher widget. Подготовленные Java/XML исходники не считаются результатом проверки. Если кандидат не подходит, обновить ADR и выбрать другую оболочку. Лицензии SDK пока не приняты.

## Цель

Выпустить настоящий Android-клиент с функциональностью пилота.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Перенести общий runtime на Android по ADR, адаптировать touch/back navigation и B2B/B2C сценарии. Реализовать локальный вход, безопасное хранение сессии, custom-scheme deep links для локального пилота, offline read cache и выбранные события в открытом приложении. Google sign-in, публичные HTTPS App Links и background push отложены. Настроить воспроизводимые APK/AAB, подпись из внешних секретов, инструкции sideload и internal testing Play.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

Устанавливаемый APK, AAB для Play, build pipeline и Android QA отчёт.
