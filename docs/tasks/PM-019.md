## Цель

Выпустить настоящий Android-клиент с функциональностью пилота.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Перенести общий runtime на Android по ADR, адаптировать touch/back navigation и B2B/B2C сценарии. Реализовать Google sign-in, безопасное хранение сессии, App Links, offline read cache, push permissions/receipt/open. Настроить воспроизводимые APK/AAB, подпись из внешних секретов, инструкции sideload и internal testing Play.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Устанавливаемый APK, AAB для Play, build pipeline и Android QA отчёт.
