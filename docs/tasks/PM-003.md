# PM-003 — UX и дизайн MarkeTOB на английском

- **Порядок:** 3; этап 1 — Требования, стек, дизайн и контракт.
- **Приоритет:** P0.
- **Состояние:** planned.
- **Зависимости:** PM-001, PM-002.
- **Открытые вводные:** использовать зафиксированные решения; новые блокеры описывать явно.
- **После этапа:** G01 — презентация и минимум 10 отдельных вопросов.

## Цель

Показать интерфейс и полный путь пользователя до реализации основных экранов.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Сделать адаптивные макеты списка каналов, каталога, новостей, графика, B2B Studio, редактора My Space, импорта, статуса заявки и виджета. Telegram-подобная навигация с собственным брендом. Показать загрузку, отсутствие данных, ошибку, запрет доступа, устаревший кеш. Для мобильного экрана — список и содержимое последовательно, для Web — две колонки.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Интерактивный прототип, дизайн-токены, состояния компонентов, текстовые сценарии.

## Критерии приёмки

- [ ] Весь UI на английском; клавиатурная навигация, контраст и touch targets проверены. Пользователь видит, откуда данные и когда они обновились. Нет обещания успешной покупки до ответа бота.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-003.md` содержит изменения, ограничения и доказательства.

## Проверка

Пройти B2B публикацию, B2C избранное/композицию/импорт/заявку на ширинах телефона и desktop; сохранить визуальные доказательства.
