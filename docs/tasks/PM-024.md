## Цель

Передать проверяемую поставку MarkeTOB для облака, APK и Google Play.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Выполнить сценарии PRODUCT_BRIEF с двумя аккаунтами и двумя ботами на release сборке. Подготовить Web build, Docker, APK/AAB, инструкции B2B/разработчика/пользователя/оператора, known issues и release notes. Настроить внутренний канал Play при доступном аккаунте; внешняя публикация выполняется отдельным явным действием владельца/запросом.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Release candidate, полная матрица приёмки, демонстрация и пакет развёртывания.

## Критерии приёмки

- [ ] Сценарии выполнены на Web и реальном Android; владелец может повторить установку и подключение внешнего бота. APK и AAB проверены. Если нет облака/Play аккаунта, конкретные внешние шаги отмечены незавершёнными и не выданы за опубликованный продукт.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-024.md` содержит изменения, ограничения и доказательства.

## Проверка

Полный happy path и ключевые failures, import privacy, news widget, offline/reconnect, clean deployment/restore и smoke после обновления.

## Фактический результат

Не выполнено. Commit/PR, артефакты и результаты проверки будут добавлены после реализации. Эта issue не закрывается публикацией плана.
