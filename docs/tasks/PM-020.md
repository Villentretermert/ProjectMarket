# PM-020 — Новостной виджет на домашнем экране Android

- **Порядок:** 20; этап 5 — Обмен, обновления, Android и виджет.
- **Приоритет:** P0.
- **Состояние:** deferred.
- **Зависимости:** PM-002, PM-018, PM-019, G04.
- **Открытые вводные:** использовать зафиксированные решения; новые блокеры описывать явно.
- **После этапа:** G05 — презентация и минимум 10 отдельных вопросов.

## Отложенное доказательство виджета

Native spike PM-002 подготовлен только в исходниках: сборка/телефон отложены владельцем. При возобновлении проверить настоящий launcher, обновление, очистку и переход; затем реализовать продуктовые private cache/TTL/logout сценарии. Не принимать эту задачу по Web-макету или успешной компиляции.

## Цель

Показывать выбранную новостную ленту вне открытого приложения.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Добавить native App Widget/bridge, выбор разрешённого источника, заголовки, время обновления, resize и переход к новости. Использовать кеш и ограниченное фоновое обновление по правилам Android; не обещать обновление каждую секунду. Удалять закрытые новости при logout/revocation; обрабатывать no network и expired session.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Рабочий виджет, настройки и инструкция пользователя.

## Критерии приёмки

- [ ] Виджет добавляется на домашний экран, показывает выбранную ленту и открывает нужную новость. На заблокированном/вышедшем аккаунте приватные данные не остаются доступны бесконечно; политика очистки и TTL проверена.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-020.md` содержит изменения, ограничения и доказательства.

## Проверка

Реальное устройство/launcher, resize, reboot, Doze/background ограничения, offline, смена аккаунта и отзыв доступа.
