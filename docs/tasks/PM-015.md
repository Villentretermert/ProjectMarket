## Ответы G03

Избранные каналы имеют сохраняемый ручной порядок.

## Цель

Сделать каналы столь же доступными, как контакты в мессенджере.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Добавить открытие URL, public preview по согласованной политике, локальный вход для сохранения, избранное с синхронизацией аккаунта, поиск/сортировку сохранённых каналов, unread/new marker по revision. Закрытый канал показывает запрос/отсутствие доступа, без раскрытия данных.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

B2C API избранного и интерфейс Channels/Favorites.

## Критерии приёмки

- [ ] Повторное добавление не создаёт дубль; сохранение доступно с другого клиента. Удаление из избранного не удаляет B2B канал. Отозванный доступ убирает приватные данные из кеша.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-015.md` содержит изменения, ограничения и доказательства.

## Проверка

Открытие прямой ссылки до/после входа, повторное сохранение, два клиента одного аккаунта, revoked/deleted channel.
