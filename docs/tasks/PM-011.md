## Цель

Дать разработчику и ИИ воспроизводимый пример подключения без управления ботами внутри продукта.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Создать Python SDK: auth, публикация сообщений, GET событий, ACK/result, retries, typed errors. Два отдельных demo bots: синтетический каталог повседневных товаров автоматически подтверждает или отклоняет заявки без оплаты; новости читают настраиваемый публичный RSS и публикуют числовой ряд для примера графика. RSS имеет офлайн-fixture для тестов. Соседний запуск через Compose profile и внешний запуск только по HTTPS API. Telegram-adapter пример получает данные из авторизованной владельцем логики.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

SDK, примеры, английский quickstart, отдельный Dockerfile бота.
