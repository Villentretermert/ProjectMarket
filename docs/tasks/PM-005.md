- **Зависимости:** PM-002, PM-004, G01.

## Цель

Создать воспроизводимую основу backend, клиентов и отдельных ботов.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Организовать apps/api, apps/client, bots/examples, packages/contracts, packages/bot-sdk, deploy и tests с адаптацией под ADR. Настроить Python, зависимости, линтер, типизацию, минимальные проверки CI, конфигурацию и .env.example без секретов. Добавить локальные Dockerfile/Compose для разработки и health endpoint; production hardening остаётся PM-021.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Запускаемый каркас, локальный Compose, CI и инструкция разработчика.

## Критерии приёмки

- [ ] Чистая копия запускается по инструкции; health доступен; CI запускает реальные проверки; секреты не нужны для обычных unit-тестов.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-005.md` содержит изменения, ограничения и доказательства.

## Проверка

Smoke test локального запуска и CI, проверка конфигурации без обязательных переменных и без встроенных ключей.
