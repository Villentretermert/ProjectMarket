1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Организовать apps/api, apps/client, bots/examples, packages/contracts, packages/bot-sdk, deploy и tests с адаптацией под ADR. Настроить Python, зависимости, линтер, типизацию, минимальные проверки CI, конфигурацию и .env.example без секретов. Добавить локальные Dockerfile/Compose для разработки и health endpoint; production hardening остаётся PM-021.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.
