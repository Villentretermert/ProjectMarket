- **Порядок:** 13; этап 4 — Web, Studio и личные страницы.
- **Приоритет:** P0.
- **Состояние:** planned.
- **Зависимости:** PM-003, PM-006, PM-009, PM-012, G03.
- **Открытые вводные:** использовать зафиксированные решения; новые блокеры описывать явно.

## Цель

Заменить демонстрационный макет англоязычным Web-клиентом на выбранном стеке.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Реализовать shell, локальный вход, список/экран канала, renderer news/product/chart, кнопки через action API, статусы/ошибки/loading/offline. Общие схемы и UI-компоненты готовить для Android. Реализовать безопасное отображение текста/URL и адаптивную навигацию. Read access проверяет backend.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Рабочий Web-клиент, документация компонентов и реальные скриншоты.

- [ ] Данные от двух ботов отображаются в браузере; закрытый канал требует доступа; действие показывает фактический статус. Нет горизонтального переполнения на телефоне, основные сценарии работают с клавиатуры.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-013.md` содержит изменения, ограничения и доказательства.

Браузерные проверки реального API, unsafe content, empty/error/offline, phone/desktop и доступности.
