## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Собрать приложение выбранным стеком, адаптировать desktop UX/Google sign-in/deep links, secure storage, уведомления, установщик и проверяемое обновление. Отдельно определить необходимость Windows Widgets; не выдавать ярлык/окно за системный виджет.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.
