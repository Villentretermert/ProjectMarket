- **Порядок:** 17; этап 5 — Обмен, обновления, Android и виджет.
- **Приоритет:** P0.
- **Состояние:** planned.
- **Зависимости:** PM-004, PM-006, PM-016, G04.

## Цель

Дать другу восстановить личный интерфейс с собственными правами доступа.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Реализовать immutable template snapshot, сериализацию layout+bindings, share code/link, import preview и создание новой PersonalPage. Предложение реализации: случайный серверный код с отзывом и optional expiry; формат подписанного offline кода рассмотреть отдельно. Не включать данные, session/bot keys или grants. Ограничить размер и разрешённые поля.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Share/Import API, UI, схема версии и формат документации.

## Критерии приёмки

- [ ] У друга совпадают размещение и совместимые виды, но закрытые источники остаются закрытыми. Изменение шаблона автора не меняет уже импортированную страницу. Отзыв кода останавливает новые импорты, но не удаляет прошлые копии.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-017.md` содержит изменения, ограничения и доказательства.

## Проверка

Импорт двумя аккаунтами с разными правами; подмена/битый/слишком большой код, неизвестная версия, deleted source, expiry/revocation.
