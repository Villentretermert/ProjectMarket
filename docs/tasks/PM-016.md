- **Приоритет:** P0.
- **Состояние:** in_progress.
- **Зависимости:** PM-004, PM-009, PM-013, PM-015, G03.
- **Открытые вводные:** использовать зафиксированные решения; новые блокеры описывать явно.
- **После этапа:** G04 — презентация и минимум 10 отдельных вопросов.

## Ответы G03

Автосохранение и Undo; My Space открывается после входа. Совместимые представления товаров/новостей переключаются.

## Цель

Позволить B2C собирать персональный интерфейс из блоков разных каналов.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Создать PersonalPage и BlockReference, выбор источников, изменение порядка, допустимый размер/оформление, выбор совместимого вида, preview/save/undo. Хранить layout отдельно от данных источника; обновлять по revision. Исключить произвольный код, SQL и автоматическое объединение несовместимых наборов данных.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Редактор My Space, persistence API и матрица совместимых визуализаций.

## Критерии приёмки

- [ ] Страница содержит минимум два разных канала и восстанавливается после входа на другом устройстве. Новости не превращаются в фиктивный числовой график. Изменение чужого блока не изменяет B2B шаблон.
- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
- [ ] Пояснительная записка `docs/task-results/PM-016.md` содержит изменения, ограничения и доказательства.

## Проверка

Сохранение/перестановка/undo, конфликт версий, отзыв доступа, удалённый блок и обновление источника; Web визуальная проверка.
