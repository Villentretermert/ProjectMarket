## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Проверить tenant/object permissions, Google sessions, bot key lifecycle, unsafe rendering, share import, cache и push privacy. Проверить удаление аккаунта/данных, retention и export по согласованной политике. Собрать список зависимостей, release конфигурацию, материалы privacy/Data Safety для Play; фактические практики сверить с текстом.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

Уточнение PM-018: проверить физическую минимизацию `change_outbox` и
`event_preferences` при удалении аккаунта/источника, cleanup retention и floor
cursor после очистки. Сейчас delivery cursor имеет TTL10min, но outbox физически
сохраняется; будущая очистка не должна повторно назначать delivery IDs или терять
подтверждённые изменения. Это часть уже запланированной политики данных PM-023.
