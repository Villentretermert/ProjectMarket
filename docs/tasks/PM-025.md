## Цель

Добавить iOS после принятого пилота без изменения контракта ботов.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Использовать общий runtime, адаптировать навигацию, Google-вход, Universal Links, push, secure storage и offline. Подготовить macOS build/signing, тестовые устройства и TestFlight через аккаунт владельца. Проверить актуальные правила магазина.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

iOS сборка, инструкции и отчёт совместимости.

- [ ] Проверки выполнены и их фактические результаты сохранены.
- [ ] CHANGELOG, STATUS, документация и GitHub issue обновлены; нет секретов в поставке.
