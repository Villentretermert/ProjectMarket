## Цель

Подготовить развёртываемую поставку сайта, API и worker на компьютере владельца (Windows + Docker с Linux containers) с переносимостью на Linux-хост.

Владелец подтвердил: «Android пока отложить; продолжить локальную поставку».
Локальная Web/API/worker-поставка и backup/restore выполняются сейчас независимо
от PM-019/020. Эти зависимости сохраняются для Android/USB/LAN-проверки общей
поставки; G05 проводится после следующих двух фактических завершений, а не
считается уже пройденной. PM-021 остаётся открытой до выполнения обязательных
проверок на компьютере владельца. Docker пока отсутствует; Linux CI и native
PostgreSQL используются как отдельные доказательства, не заменяющие Windows Docker.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Собрать Dockerfile/Compose production: API, worker, PostgreSQL, Web и HTTPS proxy; optional demo bots. Миграции отдельным шагом, health/readiness, persistent volumes, непривилегированные процессы, secrets/config, backup/restore, upgrade/rollback. Описать Windows/WSL2/Docker prerequisites, loopback и USB/LAN режим Android. Выбор VPS отложить до отдельного переноса. Объектное хранилище не считать средой выполнения Docker.
3. Выполнить критерии ниже, обновить документацию и пояснительную записку.

## Ожидаемые результаты

Docker артефакты, .env.example, локальный runbook, backup/restore и оценка ресурсов компьютера; облачные расходы сейчас не требуются.
