## Цель

Дать владельцу самостоятельный интерфейс подключения бота и публикации канала.

## Объём и порядок работы

1. Прочитать регламент, решения, зависимости и связанную GitHub issue.
2. Добавить onboarding B2B, список ботов, выпуск/ротацию ключа с показом один раз, статус, preview данных, редактор разрешённых блоков и действий, draft/publish/rollback, public/private grants и копирование ссылки. Не добавлять редактор бизнес-логики бота.
3. По G02 реализовать команды B2B: membership, минимальные серверные роли и матрицу операций, добавление существующих пользователей, изменение роли/отзыв, защиту последнего владельца и изоляцию workspace. Согласовать точную матрицу на G03; команды обязательны до внешнего пилота. Добавить напоминания о ключе за 7 дней и при истечении; новые страницы Selected users; только Request purchase, quantity=1.
4. Выполнить критерии ниже, обновить документацию и пояснительную записку.
