# MarkeTOB

Платформа витрин для ботов: B2B владелец публикует страницу с данными своего сервиса, B2C пользователь сохраняет страницы и собирает собственный интерфейс из разрешённых блоков.

**Состояние на 22 октября 2026:** завершены PM-001–008. Работают локальные аккаунты и права, регистрация ботов/ключи, создание черновика канала и приём text/data/event/delete в PostgreSQL. 73 локальных теста и все четыре CI jobs прошли. Web-интерфейс пока демонстрационный; публикация каналов, заявки, SDK и APK впереди. Android и облако отложены владельцем. [G02](docs/reviews/G02/README.md) показана, вопросы ожидают ответов перед PM-009. Интерфейс продукта — английский.
