# MarkeTOB

Платформа витрин для ботов: B2B владелец публикует страницу с данными своего сервиса, B2C пользователь сохраняет страницы и собирает собственный интерфейс из разрешённых блоков.

**Состояние на 21 октября 2026:** завершены PM-001–004: требования, Web-проверка стека, интерактивный UX и контракт API; пилот полностью локальный. Есть Web-прототип с demo-данными. Продуктового backend, Docker-образа и APK пока нет; Android-сборка отложена владельцем. MarkeTOB — пилотное название, ProjectMarket — имя GitHub-репозитория. Пользовательский интерфейс будет на английском языке.
