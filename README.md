# MarkeTOB

Платформа витрин для ботов: B2B владелец публикует страницу с данными своего сервиса, B2C пользователь сохраняет страницы и собирает собственный интерфейс из разрешённых блоков.

**Состояние на 22 октября 2026:** завершены PM-001–014. Работают локальные аккаунты и права, боты/ключи, приём данных, версии/публикация/откат каналов и чтение актуальных данных с проверкой доступа. Заявки, GET/ACK/result и восстановление после рестарта проверены; SDK и два независимых бота готовы; финальный CI: 117 tests и все четыре jobs PASS. [G02](docs/reviews/G02/README.md) закрыта; G03 закрыта после 13 ответов, блок PM-013–016 разрешён. Рабочий Web принят: 118 тестов и 14 браузерных сценариев в CI; PM-014 Studio/команды принята: 125 tests и 24 браузерных сценария CI; PM-015 избранное проходит CI; Android и облако отложены. Интерфейс продукта — английский.
